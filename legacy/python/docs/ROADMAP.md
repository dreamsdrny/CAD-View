# Python 0.1 原型开发路线（历史归档）

## 架构

采用原生桌面 PySide6 + ezdxf；单位明确的几何模型为核心，各功能通过 Document / Entity 接口协作。

1. **基础 CAD**：文件适配、二维模型、画布交互、编辑运算、历史命令。
2. **工程辅助**：几何测量、尺寸标注、图层、筛选、批量属性、图形检查、输出。
3. **PCB/FPC/SMT**：在基础模型上增加板框、钻孔、焊盘、工艺边、制造规则和 Gerber 对照；不将图层名称硬编码为对象用途。

现有几何、编辑、分析模块不依赖 Qt，可复用于批量工具或后续独立后台分析。后续大图优化应替换全场扫描，建立空间索引，并将耗时读写/检查移入工作线程。

## 0.2 · 完整二维编辑与测量

优先级 P0/P1。

- 通用曲线相交与拓扑内核：直线/圆/圆弧/椭圆混合求交；数值容差统一。
- TRIM / EXTEND：点击选择保留侧/删除侧，支持多边界和圆弧。
- OFFSET：凹轮廓、bulge、开多段线，自交清理及坍缩处理。
- FILLET / CHAMFER：两线、线圆、多段线拐角；明确半径/距离及修剪设置。
- STRETCH：窗口内顶点拉伸，保持未选顶点。
- 完整对象捕捉菜单、曲线交点、切点、最近点；空间索引提升大图捕捉速度。
- 独立测量记录对象：显示起止点、单位、精度、累计段；可导出 CSV。
- 线性/水平/垂直/角度/半径/直径标注；标注样式、精度、箭头、文字和单位。
- 查询相同尺寸、同图层、按颜色/类型/属性筛选；不将不同宽度/工艺属性的轮廓误清理。

验收方向：混合曲线边界、小尺寸高精度、闭合/自交轮廓、可撤销事务、不同单位和 10 万对象性能基准。

## 0.3 · 文档兼容与工程输出

优先级 P1/P2。

- 图纸空间/布局标签、视口、模型与纸空间比例。
- 块创建/插入/编辑、属性块、嵌套变换、分解块。
- HATCH、SPLINE、线型、宽多段线、透明度、SHX/TTF 显示适配。
- 多行文字编辑、文本对齐和字体设置。
- ODA 转换后台执行、取消、错误日志与多版本 DWG 样本验证。
- 文件转换独立入口及批量转换。
- PDF/打印机、纸张、1:1 / 1:n 工程比例、打印区域和线宽映射。
- 非法/零长度/重复轮廓检查，无用块和图层清理，修复预览。

验收方向：真实 AutoCAD/第三方 CAD 往返、块/布局/扩展属性保存、指定比例纸上尺寸比对、文件损坏与转换中断恢复。

## 0.4 · PCB / FPC / SMT 专业工程

优先级 P1。

- 工程对象角色：板框、切槽、内轮廓、NPTH/PTH、铜焊盘、阻焊、锡膏、丝印；层与角色映射配置。
- 钻孔统计：层、孔径、镀孔类型、重复孔位、钻孔表与 CSV 报告。
- 板框检查：开口、重复边、自交、凹槽、圆角、板厚及制造尺寸。
- 焊盘检查：长宽/面积/间距、细间距阵列、铜到阻焊、阻焊桥、锡膏开口；支持方向无关的真实尺寸。
- 工艺边：有效夹持宽度、定位孔/Mark 点、禁布区、传送方向与元件外形。
- FPC：折弯区、补强区、最小折弯半径、走线与折弯方向、板边到铜规则。
- SMT：拼板、元件间距、贴装边界、工艺边与定位点检查。
- Gerber RS-274X / X2 + Excellon 导入：极性、闪光/绘制/区域、孔径宏、单位和原点。
- Gerber/DXF 配准：手工基准点、旋转/镜像/平移/单位换算、半透明叠加、板框/孔位/焊盘差异报告。
- 规则模板、检查结果高亮、截图定位和 CSV/PDF 工程报告。

验收方向：真实 PCB/FPC/SMT 样本与参考 CAM 软件比对，Gerber 极性/孔径宏测试，规则来源和单位可追溯，小间距临界结果及误差报告。
