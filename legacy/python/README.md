# CAD Workbench · Python 0.1 原型归档

此目录保留重构前的功能原型。正式程序说明见项目根目录 `README.md`。下列说明为原型版本历史说明，路径相对于本目录；运行原型使用 `python main.py`。

面向二维 CAD、PCB / FPC / SMT 工程的原生桌面工作台。当前是 **0.1 可运行首版**，按“基础 CAD → 工程辅助 → 专业分析”模块化组织，后续逐步扩展 AutoCAD 常用功能。

## 启动

需要 Python 3.10 或以上版本，推荐 Windows + Python 3.12。

依赖使用 PySide6 Essentials 6.7–6.8 系列，只安装本程序需要的 Qt 桌面模块，不安装 WebEngine 等附加模块。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

安装依赖后，也可以双击项目中的 `start.bat` 启动。

也可以打开指定文件：

```powershell
.\.venv\Scripts\python.exe main.py "D:\图纸\board.dxf"
```

启动时提供一块 80 × 50 mm 演示 PCB，包含板框、四个 Ø3.2 mm 安装孔、焊盘、丝印和标注。新建空白图纸使用 `Ctrl+N`。演示图可另存为 DXF 作为后续测试素材。

可选安装入口：

```powershell
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\cad-workbench.exe
```

### 首版编辑适用范围

- 偏移：直线、圆、无圆弧段的凸闭合多边形。圆和轮廓正值外扩；直线正值沿起点→终点方向向左。
- 修剪/延伸：选择两条直线，指定目标对象及需要改变的端点，另一条作为有限边界。
- 合并：同图层、端点连续的直线；端点公差为 `0.00001` 图形单位。
- 分解：矩形/多段线拆成直线或圆弧，保留 bulge 圆弧的实际几何。
- 圆弧绘制：圆心 → 起点 → 终点，逆时针；椭圆绘制：圆心 → 长轴端点 → 短轴长度点。
- 镜像保留原对象；旋转中心可在对话框内精确设置。
- 任意修改矩形顶点后对象转换为闭合多段线，避免将变形轮廓误报为矩形。

## 操作说明

### 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+N / Ctrl+O / Ctrl+S | 新建 / 打开 / 保存 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+Z / Ctrl+Y | 撤销 / 恢复 |
| Ctrl+A / Delete | 全选可见对象 / 删除可编辑选区 |
| Home | 显示全部 |
| F3 / F7 / F8 / F10 | 捕捉 / 网格 / 正交 / 极轴追踪 |
| Esc | 结束当前工具，回到选择 |
| Enter / 右键 | 完成多段线或连续测量，回到选择 |
| C（画布获得焦点时） | 闭合当前多段线 |

左→右拖动框选完全位于窗口内的对象；右→左拖动选中与窗口相交的对象。隐藏图层不显示；锁定图层仍可选择和测量，但不能修改。

### 精确绘图和命令

在底部命令栏输入，按 Enter 执行。例如：

```text
LINE
0,0
@20,0
20<90
```

- `X,Y`：绝对坐标。
- `@ΔX,ΔY`：相对上一输入点的坐标。
- `距离<角度`：相对上一输入点的极坐标；角度单位为度，0° 向右，90° 向上。
- 单独数字：沿当前光标方向输入长度。
- 命令栏空内容按 Enter：完成当前操作。
- 多段线工具中输入 `C`：闭合；其他工具中 `C`：开始画圆。

支持命令与别名：`LINE/L`、`PLINE/PL`、`RECTANG/REC`、`CIRCLE/C`、`ARC`、`ELLIPSE`、`TEXT`、`MOVE/M`、`COPY/CO`、`MIRROR/MI`、`DIST/DI`、`ID`、`ANGLE`、`DIM/DIMALIGNED`、`AREA`（查询选中对象）、`ERASE/E`、`UNDO/U`、`REDO`、`ZOOM/Z/EXTENTS`（显示全部）、`OFFSET/O`、`ROTATE/RO`、`ARRAY`、`EXPLODE/X`、`JOIN/J`、`TRIM/TR`、`EXTEND/EX`。

### 自动几何属性

单击对象，右侧属性面板会显示：

- 圆：圆心、半径、直径、面积、周长。
- 直线：起点、终点、长度、角度。
- 矩形：长、宽、面积、周长，旋转后仍按实际边长计算。
- 多段线：顶点数、闭合状态、总长度，闭合对象另有面积、周长；含 bulge 圆弧段时采用解析面积/弧长。
- 圆弧：圆心、半径、直径、起始角、圆心角、弧长。

双击属性表或点击“编辑 / 批量修改属性”打开编辑窗口。

### PCB / FPC 工程分析

1. 默认已选择的对象为分析范围；未选择时，使用左侧范围下拉框中的可见图层。
2. 板框：只选一个闭合对象，或指定只含一个闭合板框的图层，执行“板框尺寸 / 面积”。
3. 钻孔：清除选择，将范围改为 `DRILL`，执行“孔径统计”。演示图应显示 Ø3.200 × 4。
4. 焊盘：清除选择，将范围改为 `PAD`，执行尺寸或间距检查。演示焊盘为 2 × 3 mm，水平方向边到边间距 2 mm。
5. 工艺边：只选一个板框，检查其与**其他可见图层**对象的板边距离，同时识别板框外对象；隐藏不参与检查的丝印和标注层。
6. 点击结果可高亮并将视图中心移到相关对象；下一次检查前注意清除结果产生的选择，以恢复按图层分析。

分析语义：

- 圆不自动等于钻孔；闭合轮廓不自动等于焊盘。需要工程师指定图层或选区。
- 间距检查将闭合对象视为实心区域，重叠/包含的间距为 0；板边检查使用轮廓到轮廓距离。
- 圆/直线间距采用解析计算；圆弧、多段线圆弧和椭圆用于间距计算时的离散公差为 **0.005 图形单位**。结果不作为完整 PCB DRC，暂未纳入网络、铜厚、线宽、阻焊与叠层规则。
- 普通多段线焊盘尺寸按轴对齐包围盒；原生矩形按实际边长；圆按直径。
- 板框包围尺寸是轴对齐尺寸，旋转板框与实际边长可能不同。
- 单次间距检查最多 1500 个对象；大图应按图层/选区缩小范围。首版检查与文件操作在界面线程执行。
- 单位由 DXF `$INSUNITS` 决定；未声明单位时按图形单位显示。菜单“设置图形单位”只修改单位声明，不换算坐标。

## DXF / DWG 支持

### DXF

使用 `ezdxf`，新文件输出 DXF R2010。直接显示/编辑模型空间中的二维 `LINE`、`LWPOLYLINE`、二维 `POLYLINE`、`CIRCLE`、`ARC`、`ELLIPSE`、基本 `TEXT`。

- 多段线保留 bulge、起终宽度；几何显示当前按中心轮廓，不绘制宽度带。
- `INSERT`、导入的 `DIMENSION`、`MTEXT` 和非默认对齐文字按可解析的图形只读显示，保留原对象；首版不提供块结构编辑。
- 保存以原始 DXF 文档为基础，保留图纸空间、块定义和未支持对象。原有可编辑对象尽可能原位更新，以保留线型、线宽、扩展数据等源属性。
- `HATCH`、`SPLINE`、3D/非默认 OCS 对象等暂不显示/编辑，打开后的命令记录会报告未显示对象；源对象仍保留。
- 复制/分解后产生新对象，主要继承图层和颜色，不承诺继承源对象全部扩展属性。
- 删除空图层前检查源布局、块和未支持对象的引用。保存使用临时文件后替换，写入失败时原文件保持完整。
- 字体外观取决于系统字体；当前显示和新文字使用系统字体，未实现 SHX 字体等价渲染。

### DWG（可选外部转换）

DWG 是专有格式，首版通过独立安装的 [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter) 转换。

1. 按 ODA 官方说明安装对应 Windows 版本并确认使用条款。
2. 在“文件 → 配置 DWG 转换器”中选择 `ODAFileConverter.exe`。
3. 打开 DWG：临时转为 DXF 后载入。
4. 另存为 DWG：先生成 DXF，再用转换器输出 ACAD2018 DWG。
5. 格式互转：打开文件后另存为另一种格式。

转换器路径存储在系统用户设置中，不提交到项目。**没有配置转换器时只支持 DXF，不具备原生 DWG 解码能力。** 当前环境未安装转换器，DWG 路径尚未进行真实文件验证。

## 项目结构

```text
main.py                 桌面程序入口
cad_app/
  app.py                主窗口、文件操作、属性、图层、工程分析面板、命令路由
  canvas.py             QGraphicsView 渲染、缩放、平移、选择、绘图、捕捉、交互预览

  editing.py            偏移、分解、合并、修剪/延伸
  fileio.py             ezdxf 读写、源对象保留、ODA DWG 转换适配
  analysis.py           板框、钻孔、焊盘、间距、板边、重复对象分析
tests/
  test_engine.py        几何、文件往返、源数据保留、保存失败、历史、分析
  test_ui.py            无显示器 Qt 交互测试：绘图、命令、图层、多文档
docs/ROADMAP.md          迭代路线与验收方向
```
