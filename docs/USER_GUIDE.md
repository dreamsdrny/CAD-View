# CAD · Qiao 使用说明

## 启动

程序名称为 **CAD**，图标为紫色 **Qiao**。双击 `CAD.exe` 启动后默认新建**空白图纸**，不加载 PCB 演示板；需要示例时使用“文件 → 打开演示板”。

主窗口默认采用紧凑尺寸，并按当前屏幕可用区域自动限制；首次启动不会超出桌面。调整窗口大小和位置后，正常退出会在下次启动时恢复，可用常规窗口方式缩小。右侧“对象属性 / 图层管理”默认显示，左侧“标注测量”默认收起以扩大画布；选择距离、间距、坐标等测量工具时会自动打开，也可从“视图”菜单手动显示或隐藏。画布空间不足时建议收起不用的面板。

首次启动会先弹出**操作教程 / 快速上手**窗口，涵盖视图导航、选择、绘图、测量与标注（mm / mil）、图层与工程分析、文件与编辑等要点；点击"开始使用"进入绘图界面。取消勾选"启动时显示本教程"则下次不再自动弹出，之后可随时从"帮助 → 操作教程 / 快速上手"重新打开。

安装包会建立开始菜单和桌面快捷方式；便携版请完整解压后运行，保留同目录 DLL 和 `platforms` 文件夹。

从打开原图到 SET 拼版、材料方案、导出和故障排查的完整步骤见 [使用教程](使用教程.md)；本页是常用操作摘要。

## 常用操作

- 滚轮缩放，中键拖动平移；`Home` 显示全部。
- 画布获得焦点时，方向键移动图纸（`Shift` 加速、`Ctrl` 微调），`+` / `-` 缩放；命令栏输入时方向键仍用于移动文字光标。也可从“视图 → 平移与缩放”操作。
- `Ctrl+N` 新建，`Ctrl+O` 打开，`Ctrl+S` 保存，`Ctrl+Shift+S` 另存为。
- `Ctrl+Z` 撤销，`Ctrl+Y` 恢复，`Delete` 删除未锁定对象。
  从 0.2.7 起可删除外部尺寸、只读文字/填充预览；选中外部标注的一部分会删除完整标注，选中只读块的一部分会删除该完整块实例，不影响其他引用。保存重开不再出现已删除内容，Ctrl+Z 可撤销。
- `F3` 对象捕捉，`F7` 网格，`F8` 正交，`F10` 极轴。
- 单击图形查看属性；Shift 多选；左→右框选，右→左交叉选择。
- 从 0.2.8 起修复水平/竖直白色图框、直线的零宽高显示边界导致框选失败；右→左框选实际相交笔画，左→右框选包含全部几何。只读白色文字的空隙也能点击选择。选中后按 Delete 或工具栏“删除选中”，保存重开仍保持删除；网格/坐标轴属于视图，用 F7 关闭网格，不是可删除实体。
- 绘图时 `Esc` 返回选择；多段线 `Enter` 完成、`C` 闭合。
- 命令栏支持 `LINE`、`CIRCLE`、`DIST`、`MOVE`、`COPY` 等命令。
- 精确输入：`10,20` 绝对坐标；`@5,0` 相对坐标；`20<45` 距离和角度。

### 编辑尺寸文字和公差

1. 按 `Esc` 返回“选择”，双击尺寸文字，例如 `120.000±0.2`；文字中的空隙也可双击。也可单击选中后点击工具栏 / 右侧“对象属性”中的“编辑文字 / 标注”按钮，或按 `Ctrl+E`，无需输入命令。选择可编辑文字时会自动显示对象属性面板。
2. 输入 `<>%%P0.1`，保留原实测数字并将公差改为 `±0.1`；输入 `120.00±0.1` 则使用固定显示文字。对话框会即时显示预览。
3. 点击“确定”，可用 `Ctrl+Z/Y` 撤销 / 恢复；建议第一次用 `Ctrl+Shift+S` 另存为 DXF 副本，再重新打开检查。

`%%P` / `%%p` 都显示为 `±`，也可直接输入 `±`。外部 DXF 标注目前仅支持可安全识别的单行文字，不修改板框、实测尺寸、尺寸线或箭头，不代表拉伸图形；复杂格式和嵌套标注仍只读。锁定图层不能修改。

## 标注测量

左侧“标注测量”面板实时显示测量值，并以 **mm / mil 双单位**同步显示（1 mil = 0.0254 mm）。该面板默认收起，选择测量工具时自动打开；也可从“视图 → 标注测量”手动打开。

- **对象间距工具**（工具栏或命令 `GAP` / `MEASURE`）：依次单击两个对象，自动计算间距——直线按中心线到中心线；带线宽的走线按边到边（垂直逼近时计入半线宽）；圆和弧按边到边。结果同时写入面板的测量记录。
- 每次测量会在图纸上生成一条**标注**（尺寸线加双单位文字），随 DXF 保存，可像普通对象一样选择、移动或删除。标注字高默认随间距自适应（小间距自动用小字），选中后在"编辑 / 批量修改属性"里可改"标注字高"。
- 面板中的测量记录可单击定位对象；悬停绘图区时显示实时预览。
- 状态栏与"坐标"命令（`ID`）以 **mm / mil 双单位**显示光标坐标，默认以图纸原点 (0,0) 为基准；可用"视图 → 设置坐标原点"把当前光标位置设为原点，"重置坐标原点"恢复 (0,0)。
- 单位换算按图纸声明的单位（DXF `$INSUNITS`，可用"文件 → 设置单位"修改）；未声明单位的图纸按 1 图形单位 = 1 mm 处理，面板会给出提示。设置单位只影响 mm / mil 换算，不缩放坐标；修改单位后标注文字即时刷新。

## 工程分析

### 拼版 / 材料方案（0.3.0）

0.3.0 起只有**一个“拼版”窗口**：菜单“工程分析 → 拼版”、工具栏“拼版”或命令 `PANEL` / `PANELARRAY`。旧命令 `FPCPLAN` / `MATERIAL` 也打开同一个窗口，不再单独弹出材料窗口。

窗口内分两页：

- **拼版 SET**：从单 PCS 外轮廓生成 SET。可框选单板区域自动识别，也可手动确认准确外形线；设置行列、旋转 / 交错、固定 SET、工艺边与自动 / 手动连接筋，查看 PCS、ARRAY、SET 长宽和实际最小净距，然后点“生成新拼版图纸”。结果在主窗口**新标签**打开，请 `Ctrl+S` 保存；原文件不修改。
- **材料方案 / 利用率**：当前 SET 自动作为第一个比较方案。输入材料尺寸、四边预留、间距、方向、订单 / 良率，比较或搜索不同 PCS→SET 拼法，查看 SET 占料率、PCS 真实面积利用率、最低材料张数和预计出货；选中方案可“应用到 SET 拼版”，再回拼版页重新生成工艺边 / 连接筋。

可选设计图 / 融合图、是否带尺寸 / 参考轮廓，以及 DXF / PDF / DWG 格式。DWG 需 ODA；PDF 非 1:1。材料页支持 CSV 计算表、PDF 对比报告、DXF / PDF / DWG 大料图。修改输入后旧结果失效，须重新计算；搜索不是最优排料承诺，预计出货不是保证；硬板规则未纳入。

详细操作、公式、净距 / 步距区别与限制见 [拼版与材料方案说明](PANELIZATION.md)。

选区优先；没有选择时使用左侧指定图层。演示板可用 `BOARD` 检查板框、`DRILL` 统计孔径、`PAD` 检查焊盘和间距。单击检查结果定位图形，再次按图层检查前清除选择。

当前分析是几何工程辅助；圆不会自动识别为真实钻孔，结果按文档单位显示。曲线离散目标误差为 0.005 图形单位，实际误差上界显示在命令区，超过分段预算时检查停止。暂不包括网络、线宽、阻焊和叠层规则。

## 文件支持

### 自动恢复未保存的图纸

- 程序每 **60 秒**检查所有打开文档，把有修改的文档写成独立恢复快照；也可点击“文件 → 立即创建恢复快照”。后台写入不阻止继续绘图，**不会覆盖原 DXF / DWG，也不会把文档标记为已保存**。
- 异常退出后，正常启动时会显示“恢复未保存图纸”。选中需要的快照，点击“恢复选中”；也可从“文件 → 恢复未保存图纸…”进入。未命名文档同样支持恢复。
- 恢复图纸标题带“已恢复”，以未保存副本打开。按 `Ctrl+S` 会要求选择保存位置；建议另存为新的 DXF 文件。原文件路径在恢复列表和命令区显示，恢复前的撤销历史、选择、测量面板记录和视图状态不恢复。
- “稍后处理”保留快照；“丢弃选中…”会再次确认，仅删除选中的快照，不删除原图。正常保存、关闭并明确放弃修改后清理对应快照；取消关闭不会删除其他文档的快照。仍在运行的另一实例的快照不参与恢复。
- 快照位于当前用户的 Qt 本地应用数据目录下的 `recovery` 子目录（Windows 通常为 `%LOCALAPPDATA%\EngineeringTools\CAD\recovery`），使用原子写入和 SHA-256 完整性校验。命令区会显示写入失败，损坏快照不会阻止打开其他图纸。
- 自动恢复不是备份系统：尚未成功生成快照的修改不能恢复；60 秒是检查周期，大图排队或写入时可能更久。快照 DXF 数据限制为 256 MiB，沿用现有二维 DXF 兼容边界。请继续定期手动保存并保留原始 DWG 备份。

当前直接读写 ASCII DXF，支持主要二维图元。新建文字为单行；后台打开可取消，DXF 大小默认限制为 256 MiB。尚未支持显示的块、填充、复杂文字、布局和 3D 源记录会保留，打开后命令区会报告。

从 0.2.3 起，程序自带 LibreDWG 读取引擎，直接打开原始 DWG，无需先转 DXF 或配置转换器。识别 R11/R12 至 2018 系列标准格式；不同 CAD 软件生成的标准 DWG 按格式解析，而非按软件名称判断。完整目录包请保留 `tools/libredwg`；单文件 EXE 已包含读取引擎。

若已安装 ODA File Converter，程序优先使用它；也可在“文件 → 配置 DWG 转换器”指定路径，或设置 `CAD_ODA_CONVERTER`。**保存为 DWG 仍需要 ODA**，没有 ODA 时普通保存会进入 DXF 另存为，不直接改写原 DWG。建议保留原始图纸备份，转换不保证无损。

读取失败时会明确报错，不再自动打开同名 DXF。专有代理对象、复杂块、填充、MTEXT、布局和 3D 等内容不保证完整显示；命令区会报告版本、使用引擎和兼容性警告。能打开文件不等于与原软件完全一致。

PDF 输出按页面适配；精确比例打印、圆角/倒角、完整块编辑和 Gerber 对照仍在后续开发路线中。
