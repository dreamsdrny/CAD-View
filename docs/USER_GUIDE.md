# CAD · Qiao 使用说明

## 启动

程序名称为 **CAD**，图标为紫色 **Qiao**。双击 `CAD.exe` 启动，默认打开 PCB 演示板。

安装包会建立开始菜单和桌面快捷方式；便携版请完整解压后运行，保留同目录 DLL 和 `platforms` 文件夹。

## 常用操作

- 滚轮缩放，中键拖动平移；`Home` 显示全部。
- `Ctrl+N` 新建，`Ctrl+O` 打开，`Ctrl+S` 保存，`Ctrl+Shift+S` 另存为。
- `Ctrl+Z` 撤销，`Ctrl+Y` 恢复，`Delete` 删除未锁定对象。
- `F3` 对象捕捉，`F7` 网格，`F8` 正交，`F10` 极轴。
- 单击图形查看属性；Shift 多选；左→右框选，右→左交叉选择。
- 绘图时 `Esc` 返回选择；多段线 `Enter` 完成、`C` 闭合。
- 命令栏支持 `LINE`、`CIRCLE`、`DIST`、`MOVE`、`COPY` 等命令。
- 精确输入：`10,20` 绝对坐标；`@5,0` 相对坐标；`20<45` 距离和角度。

## 工程分析

选区优先；没有选择时使用左侧指定图层。演示板可用 `BOARD` 检查板框、`DRILL` 统计孔径、`PAD` 检查焊盘和间距。单击检查结果定位图形，再次按图层检查前清除选择。

当前分析是几何工程辅助；圆不会自动识别为真实钻孔，结果按文档单位显示。曲线离散目标误差为 0.005 图形单位，实际误差上界显示在命令区，超过分段预算时检查停止。暂不包括网络、线宽、阻焊和叠层规则。

## 文件支持

当前直接读写 ASCII DXF，支持主要二维图元。新建文字为单行；后台打开可取消，DXF 大小默认限制为 256 MiB。尚未支持显示的块、填充、复杂文字、布局和 3D 源记录会保留，打开后命令区会报告。DWG 需要独立安装 ODA File Converter 并在文件菜单配置路径。

PDF 输出按页面适配；精确比例打印、圆角/倒角、完整块编辑和 Gerber 对照仍在后续开发路线中。
