# 0.3.0 拼版与材料方案合并 / 单一拼版窗口

## 界面

- 菜单、工具栏、命令入口只保留“拼版”（`PANEL` / `PANELARRAY`）；软板材料方案不再单独显示。
- “拼版”窗口顶部改为两个页签：**拼版 SET**、**材料方案 / 利用率**。
- 拼版页保留“原图外轮廓选择”“拼版预览 / 连接筋”；材料页保留“方案与产出比较”“大料排布预览”。
- 旧命令 `FPCPLAN` / `MATERIAL` 仍然可用，但打开同一个拼版窗口，不再弹出独立材料对话框。
- 删除重复的独立材料窗口类和工具栏 / 菜单项，材料逻辑作为拼版窗口的一部分维护。

## 功能

- 当前 SET 自动成为材料页第一个比较方案；拼版参数变化后自动更新并让旧结果失效。
- 首次切换到材料页自动比较一次；手动比较、后台搜索、取消、结果排序、基准比较保持原行为。
- 选中带真实几何的方案可“应用到 SET 拼版”，回填行列、旋转、固定 / 步距、交错和手动筋，并切回拼版页重新生成。
- “生成大料排布图”通过拼版窗口的回调在主窗口新标签打开；不自动保存。
- CSV 方案计算表、PDF 对比报告、DXF / PDF / DWG 大料图导出保留；修改输入后仍必须重新计算。
- 原图、拼版图、材料图仍互不覆盖；源 DXF 路径不可作为导出目标。

## 测试

- `core`、`panel`、`fpc_material`、`recovery`、`benchmark` 保持通过。
- `ui` 覆盖合并窗口、材料页自动比较、后台搜索、取消后不可导出、应用到 SET、生成大料图、原图隔离。
- 独立 `PanelizationInterop.py` 和 `FpcMaterialInterop.py` 仍可用于 DXF 几何与 CSV 算术复核。

## 边界

- 仍仅软板二维几何及数量规划，未实现硬板 V-cut、铣边补偿、叠板、铜层、层压、补强方向或强度规则。
- 拼版和材料搜索都是有限候选比较，不承诺全局最优；预计出货不是保证。
- PDF 仍为适合页面输出，不是 1:1；保存 DWG 仍需 ODA。
