# 原生 C++ 迭代路线

## 0.2 · 已落地

- C++20 / Qt 6 / CMake 四个模块：core、io、engineering、ui。
- 多文档、基本二维绘制、常用编辑、测量/对齐标注、图层与属性。
- 原生 ASCII DXF 适配及源记录保留，ODA DWG 外部转换。
- 批量绘制、视口裁剪、路径缓存、BVH 空间查询、增量撤销。
- 后台文件/检查任务、C++ 与 Qt 交互测试、独立 DXF 审计。

## 0.3 · CAD 兼容与可靠性

1. DXF/DWG SDK 选型与真实文件样本集：优先块、传统多段线、外部标注、多行文字、填充、样条和布局。
2. 明确属性继承、线型/线宽/透明度、字体、OCS/3D 处理；新增无损往返兼容矩阵。
3. 任务进度、取消、超大文件读取、错误定位、恢复/自动保存。
4. 曲线拓扑：完整求交、凹轮廓偏移、自交处理、通用 TRIM/EXTEND、FILLET/CHAMFER、STRETCH。
5. 完整标注：水平/垂直/角度/半径/直径、样式、箭头、单位/精度。
6. 块创建/编辑、HATCH、多行文字、按属性筛选、图形修复与无用图层/块清理。

## 0.4 · 大图性能与工程输出

- 10 万/100 万对象真实图纸 benchmark，明确加载耗时、峰值内存、编辑延迟和帧率。
- 后台路径准备、增量空间索引、按屏幕像素的曲线精度/LOD、批量 GPU 渲染评估。
- 图纸空间、视口、指定比例 PDF/打印机、纸张/区域/线宽。
- 性能回归测试、工程报告 CSV/PDF、安装包与版本发布。

## 0.5 · PCB / FPC / SMT

- 图层/角色映射：板框、孔、铜、阻焊、锡膏、丝印、折弯、补强。
- 真正钻孔表、PTH/NPTH、定位孔/Mark 点、重复孔位、板框开口/自交检查。
- 网络/线宽感知的间距、阻焊桥、锡膏开口、细间距阵列、FPC 折弯禁布与补强规则。
- Gerber RS-274X/X2 + Excellon 导入，极性/宏/单位测试。
- Gerber/DXF 配准、叠加、板框/孔位/焊盘差异与可追溯报告。
- 与参考 CAD/CAM 软件比对真实 PCB/FPC/SMT 文件，发布兼容性和规则适用范围。
