# 0.2.9 软板材料方案 / 利用率 / 出货计算

- 新增“软板材料方案”（`FPCPLAN`/`MATERIAL`）和拼版内联入口，将 PCS→SET 与 SET→Panel 两级分别计算。
- 已有 SET 多方案比较，支持材料 mm/in 换算、四边预留、X/Y间距、0/90°方向及左右/上下分区混排。
- 带真实 PCS 的有限后台搜索比较行列、数量、旋转及交替行/列180°紧排，并验证实际轮廓重叠/净距；可取消/预算停止。
- 工艺条件包括 PCS/SET数量范围、SET X/Y尺寸上下限、PCS方向限制；自动结果可应用回 SET 拼版，再重新生成工艺边和连接筋。
- 分别显示 SET占大料/工作区、去边SET占料、PCS真面积利用率，面积未知明确标记。没有把单板外接矩形当作实际单板面积。
- 订单、现有材料张数、预计良率、PCS/完整SET交货规则；计算毛产出、预计出货、最低材料张数和超交。预计值不保证实际出货。
- 可选基准比较面积变化、PCS/Panel变化、利用率百分点、材料张数变化，CSV和PDF报告包含对比数据。
- 生成大料排布新图，导出CSV、PDF报告、DXF/PDF/可选ODA DWG，详细PCS预览受顶点和数量预算限制。
- 原有白色图框/文字删除与源实例删除功能保持，硬板工艺本次未实现。

详细公式、截图数据不一致的口径说明与搜索边界见 [软板材料方案说明](FPC_MATERIAL_PLANNING.md)。版本缓存独立为0.2.9，不复用旧便携程序。
