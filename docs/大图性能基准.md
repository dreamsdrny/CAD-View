# 大图性能基准

`cad_benchmark` 是开发测试程序，不是交付程序。每次单独启动进程，使用 Qt offscreen 平台在 1280×800 图像上绘制；JSON 记录平台、文件、显示对象数、警告、各阶段耗时和进程峰值常驻内存。单次结果受机器负载、缓存、窗口系统和图纸内容影响，**不是帧率保证，也不是中望 CAD 的对比结果**。

## 运行

先按 README 构建，Windows PowerShell 中：

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
.\build\native\bin\cad_benchmark.exe --count 100000 --iterations 10 --output "$env:TEMP\cad-100k.json"
.\build\native\bin\cad_benchmark.exe --input 'D:\图纸\board.dxf' --iterations 10 --output "$env:TEMP\cad-drawing.json"
```

生成模式支持 `--count 1..500000`，默认 100000；`--iterations` 为 1..100，默认 10。文件模式支持 DXF/DWG，DWG 取决于转换引擎配置；不写 `--output` 时输出到标准输出。使用相同机器、同一图纸、同一构建、相同参数多次独立运行后比较，不要把不同文件的对象数或解析复杂度视为相同负载。CTest 的 `benchmark_smoke` 只检查程序可运行，不设跨机器性能阈值。

`timeMs` 字段单位为毫秒：

- `loadOrGenerate`：文件读取、转换和解析；合成模式是文档生成时间，**不是 DXF 解析时间**。
- `canvasAndIndex`：创建画布、缓存实体及建立空间索引。
- `fit`：计算显示全部范围。
- `firstPaint`：显示全部后首次离屏绘制，包含路径首次生成。
- `warmPaint`：首次绘制后重复绘制的 min/median/p95/max/mean。
- `zoomAndPaint`：一次放大及随后绘制。
- `panAndPaint`：模拟中键平移并绘制，报告多次分布。
- `total`：该进程内所有测量阶段总时间；峰值常驻内存为整个进程的历史峰值，不是各阶段增量，Windows 读取 PeakWorkingSetSize，Linux 读取 ru_maxrss，不支持的平台为 -1。

## 本机参考结果

2026-11-19，Windows 11 23H2、Intel i7-12700H、Qt 6.8.3、Release、每项重复 10 次。分别独立运行一次；生成数据为 10 万条分布式直线，真实图纸为 `TF0S003A-621-02[V03.dxf`（15,071,465 字节）。下列为该次观测值，不是验收阈值：

| 指标 | 10 万合成直线 | 真实图纸 |
| --- | ---: | ---: |
| 显示对象 | 100,000 | 188,525 |
| 生成 / 读取解析 | 55 ms | 1,862 ms |
| 画布及索引 | 114 ms | 247 ms |
| 显示全部计算 | 26 ms | 63 ms |
| 首次绘制 | 171 ms | 320 ms |
| 重绘中位 / p95 | 68 / 69 ms | 144 / 161 ms |
| 平移及绘制中位 / p95 | 65 / 66 ms | 147 / 160 ms |
| 放大及绘制 | 67 ms | 153 ms |
| 进程峰值常驻内存 | 499 MiB | 1,061 MiB |

真实图纸仍有无法完整显示的对象，程序会输出警告；性能随支持对象增加而变化。当前首次可见路径与空间索引仍在界面线程构建，实体缓存和路径会占用较多内存。离屏绘制没有测量 GPU、真实窗口合成、显示器刷新率，也未测量交互输入延迟、多文档和长期运行。
