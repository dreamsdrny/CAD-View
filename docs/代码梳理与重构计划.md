# 代码梳理与重构计划

## 目标和原则

面向看图、测量、绘图与编辑，采用现代精简界面，优先稳定性、大图交互和可维护性。既有 DXF/DWG 兼容、源记录保留和用户图纸不因重构被删除；每一阶段可编译、可测试、可回退。当前是第一阶段，并非全部模块已重写或完整商业 CAD 兼容。

## 模块清单

| 模块 | 主要代码 | 职责和当前风险 |
| --- | --- | --- |
| 品牌 | `src/branding` | 名称、图标与样式；界面颜色和布局仍需逐步统一。 |
| 数据与几何 | `src/core` | 图元、文档、撤销、几何和空间索引；实体类型共用结构，调用方需注意每种类型的几何约束。 |
| 文件 | `src/io` | DXF 组码解析、源记录保存与 DWG 外部读取；仍有不支持的文字、填充、样条、3D 等对象，不能假设完全兼容。 |
| 工程分析 | `src/engineering` | 板框、孔径、间距、工艺边等；需要持续明确几何假设和未参与计算的对象。 |
| 界面 | `src/ui` | 主窗口、命令、画布、后台任务；主窗口仍集中管理较多职责，后续应拆出任务和命令控制器。 |
| 测试 | `tests/native` | 核心、交互、互操作和真实图纸可选测试；商业软件显示结果仍需参考图与人工核验。 |
| 构建与发布 | `CMakeLists.txt`、`scripts` | Qt/MinGW 构建、测试、DWG 依赖和打包；打包需在发布环境重新验证。 |

## 第一阶段已完成

- 图层与属性合并为右侧页签，工程分析面板默认隐藏，可从“视图”打开，运行工程分析时自动显示；保留菜单、快捷键和命令栏。
- 精简工具栏和样式，画布绘制路径按需生成；选择和缩放模式下跳过不必要的对象捕捉查询。图元变动后仍会重建空间索引，首次显示大范围时仍须生成可见对象路径。
- 坐标解析拆为 `src/ui/CommandParser.*`，增加界面布局、命令、路径缓存、选择和导出回归测试。
- 重新编译并运行核心、界面测试；以用户指定的 DXF 验证可打开。未做中望 CAD 截图逐像素对照，也未做性能基准承诺。

## 后续阶段

1. 已建立离屏大图基准，见 [大图性能基准](大图性能基准.md)；后续补充真实窗口、多文档和异常关闭测试。
2. 拆分主窗口职责：独立文件任务、命令注册、面板和状态控制器，补充后台取消、保存与文档关闭的交互测试。
3. 减少大图内存和重复遍历，评估增量空间索引、路径缓存淘汰和按屏幕精度绘制；只有实测后才能给出性能结论。
4. 按真实文件完善 DXF/DWG 与中望 CAD 的视觉和坐标对照；对无法安全编辑的对象继续保留源记录并明确提示。
5. 完善可访问性、键盘操作、布局恢复、绘图与测量流程，以及独立互操作和发布包验证。
