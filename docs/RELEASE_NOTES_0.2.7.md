# 0.2.7 删除外部图纸内容与自动拼版

## 修复 / 新增

- DXF 的外部尺寸、MTEXT、填充、样条预览和部分显示的只读块不再被 Delete 静默跳过。只读限制仍保护几何修改，但可通过源实例事务删除，支持撤销/恢复、保存重开和自动恢复。
- 删除外部 DIMENSION / 只读 INSERT 的任一预览部分会删除**整条尺寸 / 整个该块实例**；共享 BLOCK 定义及其他引用保持不变。锁定层仍不能删除；跨层只读块包含锁定层时整个实例保留。
- 按源身份维护显式删除集合，DXF 输出移除对应模型空间记录，不只是隐藏线条。未选择的未支持记录继续保留。
- 工具栏和工程分析入口统一改为 **拼版**。
- 自动识别所选区域中的闭合外形；未选择时尝试当前可见图。忽略文字、外部标注预览、悬挂线，合并公差内重复投影，提供真实外形候选，不用矩形替代。
- 自动预览默认 2×2（可设置数量），支持固定 SET 和自动数量；生成按钮即使尚未手动确认轮廓也会尝试识别，并在失败时显示原因。
- “生成新拼版图纸”提交生成的 Document 快照，在主窗口打开新标签、显示全部并聚焦；不会仅关闭预览、不提交结果。生成没有自动保存，请 Ctrl+S 或使用导出。
- 同尺寸不同凹口/旧新版本自动候选生成前要求确认；区域合并产生的折线近似会标明并要求确认。软件不推断最终制造版。
- 拼版原图副本提供“删除选中内容（仅此副本）”和“撤销清理”；不修改主窗口原文档。

## 验证

- C++ 核心覆盖实例删除、共享尺寸块、锁定层、撤销/恢复和保存重开。
- UI 覆盖鼠标交叉框选外部尺寸再 Delete、自动识别无预选图纸、点击生成后新标签实际 PCS 数量及文件往返。
- E2 原图回归覆盖清除多余外部内容、自动识别 65.3×22.9 外形、确认候选并生成 4 PCS；不使用错误的 set.dxf。
- 恢复测试覆盖已删除的外部尺寸不会在恢复文件中重现。
- `tests/native/DeleteInterop.py` 使用独立 ezdxf 审计删除实例：共享块与另一条尺寸不变、源文件哈希不变、无错误/无自动修复。

## 分发

版本提升为 0.2.7，单文件便携 EXE 使用独立缓存目录 `%LOCALAPPDATA%\Qiao\CAD-Portable\0.2.7`，不会复用旧 0.2.6 程序。便携 ZIP 和安装包均由新的干净 staging 目录制作，不含测试程序。

开发时原程序正在使用未保存图纸，可以在独立 build 目录编译、测试，再通过 `scripts/package-native.ps1 -SkipBuild -BuildDirectory <已验证构建目录>` 打包，不覆盖正在运行的 CAD.exe。

## 仍有限制

只读块不支持单独删除内部预览子图形（删除的是整个实例）；完全未显示的对象无法用框选定位。自动识别并非制造版自动裁决，也不是任意图纸的最优排料；不要在含多视图/旧新轮廓的整图中未经检查使用第一个候选。DWG 输出仍需 ODA，PDF 为适合页面而非 1:1，自动连接筋需工艺审核。
