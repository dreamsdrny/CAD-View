# 0.2.5 启动空白图纸与紧凑窗口

## 启动行为

- `MainWindow` 默认不再加载演示板，正常启动和 `--check-open` 均从空白文档开始。
- “文件 → 打开演示板”保留，PCB 演示仍可作为新标签页打开。
- 启动日志提示空白图纸及演示板入口，避免用户误以为示例丢失。

## 窗口与布局

- 首选窗口尺寸 1180 × 760，并限制在屏幕可用区域的 92% 宽、88% 高以内；最小 640 × 480。
- 退出时把 `saveGeometry()` 写入 `ui/windowGeometry`，下次启动恢复；恢复后检查窗口是否仍在当前屏幕可用区域内。
- 左侧“标注测量”默认收起；选择测量类工具（距离、间距、水平、垂直、连续、角度、坐标）时自动显示并置顶。
- “标注测量”“对象属性”“PCB / FPC 工程分析”的最小宽度分别降到 210 / 240 / 230，底部命令记录高度降到 104，减少对画布的挤压。
- 窗口几何的读写沿用原有 `QSettings("EngineeringTools","CADWorkbenchNative")`；测试模式不读写几何，避免测试之间互相影响。

## 回归覆盖

- `UiTests` 新增 `compactBlankStartupAndExplicitDemo`：验证启动为空白单文档、无 PCB 标题、窗口不超过紧凑尺寸与屏幕可用区域、三处面板最小宽度、测量面板默认隐藏并在选择间距工具后显示、演示板菜单仍打开 26 个实体。
- 原有测量记录用例先显式显示面板，避免依赖旧的默认可见状态。
- 全量构建后 CTest 四组全部通过；真实 Windows 平台 11 个交互/恢复用例通过。
- 源码版与单文件便携版启动截图均确认空白图纸、0 对象。

## 已知限制

- 高 DPI 下 `QWidget::grab()` 返回物理像素，部分既有像素取色用例按逻辑坐标断言，在真实 Windows 平台会偏位；这些用例与主窗口启动改动无关，以离屏结果为准。
- 窗口几何恢复仅做屏幕可用区域兜底，不记录显示器编号；多显示器拔插后窗口可能出现在主屏。
- 安装包已构建但未执行真实安装/卸载验收。
