# 0.2.8 白色图框/直线框选删除修复

## 根因与修复

之前左→右框选使用 `QRectF::contains(QRectF)` 检查显示路径边界，水平直线/竖直直线的边界宽高之一为零，Qt 将其视作空矩形而拒绝包含。因此白色直线虽然显示正常，但框选没选上，删除操作无目标。与颜色、图层锁定无关；黄色复杂尺寸块通常有非零宽高。

- 左→右框选改用几何边界坐标比较，零宽高的横竖直线正确参与选择。
- 右→左交叉框选同时检查实际路径笔画，不再仅依赖填充区域，能够选中被框穿过的白色图框线/短线。
- 只读白色 MTEXT / 对齐文字的文字间空隙也纳入点选命中范围，不必精确点到字的笔画。
- 旧版 DXF 的 `\M+...` MIF 编码按对应东亚字符集解码预览，避免公司名称显示为长串转义字符并把选择边界撑出标题区；未修改源记录保持原始编码。
- 新增工具栏“删除选中”，沿用 Delete 操作；没有选中目标时明确说明如何框选，网格/坐标轴不是图纸实体。
- 延续 0.2.7 的源实例删除、撤销/恢复、锁定保护和保存重开能力；不把只读预览改成可任意修改的几何。
- 删除尺寸时同步移除属于该尺寸的扩展字典与 DIMASSOC 关联对象，避免导出中出现悬空 owner。共享块及其他实体的关联对象保留。

## 实际参考图验证

输入：`D:\Evan\Seyond问题\11-19电机的拼版图\红版\E2-FPC-PANLE-20261124.dxf`，仅只读验证，不覆盖原图。

- 原参考 SET 120×150 mm，10 个 `12331` PCS 块引用，5 个 90° + 5 个 270°，均 1:1 正缩放，无隐式镜像。
- 鼠标从左→右框选原工程图框/标题区，Delete 删除白色直线和文字，再保存、重开、撤销/恢复；右侧参考拼版 10 个 PCS 保持不变。
- 全选所有显示对象再删除，保存重开没有显示对象；源中未支持/未显示的 LEADER 仍保留，不能把空画布理解为源文件里所有未支持记录都已删除。
- 在参考文件原单板区提取真实 65.3×22.9 mm 外形，以固定 SET 120×150、90°、常规 2 mm 外接框净距进行自动行列拼版；当前常规阵列得到 **8 PCS**。参考图的 **10 PCS** 是交错套排、交替列旋转/偏移，不能声称常规行列已经等价复现；第一版未实现该布局的全自动最优嵌套排料。
- 独立读取器检查参考框、旋转、数量、清理输出和固定 SET 输出尺寸；几何生成/标注定义点/显示数字一致。新生成图无格式审计错误/自动修复；原参考本身含 SORTENTSTABLE owner 修复项，清理输出不得引入额外错误/修复，保留原始未修改记录。

开发验证变量：`CAD_TEST_PANEL_REFERENCE` 指定上述参考；`CAD_TEST_PANEL_OUTPUT` 指定生成的 120×150 文件基名；`CAD_TEST_PANEL_UI_OUTPUT` 指定白色图框清理后的文件/截图基名。独立检查脚本为 `tests/native/PanelReferenceInterop.py`。
