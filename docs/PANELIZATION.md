# 拼版与软板材料方案（0.3.0）

> 0.3.0 起，“拼版”和“软板材料方案”合并为**同一个窗口**。
> 菜单、工具栏、命令都只保留一个入口：**工程分析 → 拼版**，命令 `PANEL` / `PANELARRAY`。
> 窗口内用两个页签分工：
>
> | 页签 | 解决的问题 |
> | --- | --- |
> | **拼版 SET** | PCS → SET：外轮廓、行列、旋转、净距、工艺边、连接筋、融合、尺寸、导出 |
> | **材料方案 / 利用率** | SET → Panel：材料尺寸、工作区、排料、利用率、备料、预计出货、报告 |
>
> 旧的 `FPCPLAN` / `MATERIAL` 命令仍然可用，但会打开同一个“拼版”窗口，不再单独弹材料窗口。

---

## 1. 入口与操作顺序

1. 打开正确的单板 DXF。
2. 在画布上框选**单 PCS 实际外形区域**，或先不选、让窗口识别当前可见图。
3. 打开“拼版”窗口，在“原图外轮廓选择”页确认外轮廓。
4. 在“拼版预览 / 连接筋”页设置行列、旋转、净距、工艺边和连接筋。
5. 看底部 `PCS / ARRAY / SET` 尺寸、实际最小净距和警告。
6. 需要判断材料利用率时，切到“材料方案 / 利用率”页；当前 SET 会自动成为第一个比较方案。
7. 选择方案后点“应用到 SET 拼版”，回到拼版页重新生成工艺边和连接筋。
8. 分别生成拼版图、大料排布图，并另存。

**顺序不要颠倒：先确认 PCS 外形，再排 SET，最后算大料。**  
PCS 外形未确认时，材料页只能做矩形尺寸估算，不能代表真实单板面积。

## 2. PCS → SET

### 2.1 外轮廓确认

支持分段 `LINE`、`ARC`、`LWPOLYLINE`、传统 `POLYLINE` 和 `CIRCLE`。组装后保留圆弧；多条独立闭合轮廓作为候选，不自动把孔加入模板。

打开窗口会自动识别：

- 有选区时识别选区；
- 无选区时识别当前可见图形；
- 自动排除文字、外部标注和悬挂线；
- 闭合外形候选按面积排序；
- 默认预览 2 × 2。

建议在整张工程图包含图框、多个视图或旧版重叠轮廓时，先在主画布框选单板区域，再打开窗口。

如果外轮廓有断口或分叉，界面会显示问题端点坐标。取消错误边、补齐后重新确认。颜色不是版本判据，软件不猜哪个是修改版。同长宽但不同凹口的候选必须人工确认。自动区域合并产生的折线近似会标“折线近似”，手动准确选边优先保留圆弧。

参考文件 `set.dxf` 不是有效模板。示例请用原始 E2 DXF 和红版 `E2-FPC-PANLE-20261124.dxf` 对照。

### 2.2 三组尺寸

| 尺寸 | 含义 |
| --- | --- |
| **PCS** | 第一块放置后单板外形的 X/Y 长宽；90° 旋转后交换 |
| **ARRAY** | 所有放置 PCS 的真实几何外接矩形，不含文字、箭头、线宽、工艺边、连接筋 |
| **SET** | 含四边预留的整版目标长宽 |

尺寸由真实几何和定义点生成，画布、PDF、DXF 标注共用同一套布局。显示数字按小数位舍入，不等于对模型坐标舍入。

**生成后的拼版是普通实体，不是参数化模型。** 手动移动 PCS 后，旧尺寸不会自动跟着变，需要重新生成。

### 2.3 排布参数

| 参数 | 说明 |
| --- | --- |
| 整体旋转 | 0° / 90° / 180° / 270°，只旋转，不镜像 |
| 行数 / 列数 | 每行 / 每列放几个 PCS |
| 固定 SET / 大板尺寸 | 勾选后使用指定 SET 宽高，余量居中 |
| 自动计算数量 | 按 SET 尺寸反算行列；不是最优排料，会禁用行列输入 |
| 使用步距 | X/Y 输入变成相邻基点步距，而不是外接框净距 |
| X / Y 净距或步距 | 普通模式是净距；步距模式是相邻列 / 行基点 ΔX / ΔY |
| 隔行 / 隔列旋转 180° | 非镜像 |
| 隔行 X 偏移 | 交错排布的水平偏移 |
| 真实轮廓最小净距 | 按真实直线 / 圆弧检查的最小间距 |

普通模式下，步距 = PCS 外接宽/高 + 净距。步距模式直接输入 ΔX / ΔY。

两种模式都会：

- 按闭合外形区域检查重叠 / 包含；
- 按真实直线和圆弧检查最小净距；
- 不用包围盒距离代替最终净距。

限制：

- 最多 400 PCS；行列各最多 100。
- 只有平移和 0/90/180/270° 旋转，禁止镜像和缩放。
- 固定 SET 是“扣除四边预留后放得下多少”，余量居中，不是任意角度最优排料。

**参考拼版不等于规则网格。** 红版 `E2-FPC-PANLE-20261124.dxf` 是 120 × 150 mm、10 PCS 的交错排布；同一单板按规则网格可能只得到 8 PCS。参考文件包含实际生产排法，不能把“10 PCS”当作固定模板套到别的参数上，也不能反过来假设规则网格一定能复现它。

### 2.4 工艺边与连接筋

四边预留应不小于“工艺边宽 + PCS 到工艺边最小净距”。

- “整体四边工艺框架”生成四条材料边，不是实心矩形。
- 未连到工艺框的 PCS 会警告。
- 自动筋是邻近 PCS / 工艺边之间的最短连通建议，**不校核铜层禁布、强度、鼠咬孔、V-cut 或加工可行性**。
- “建议筋 → 手动编辑”可把建议转成表格，再调整端点 / 筋宽或删除。
- “手动筋：点两端”可在预览中直接放置。
- 连接筋坐标是 **SET 内绝对毫米坐标**，不是 PCS 本地坐标。
- 连接筋必须实际接触两个材料区域才有效；越过其他 PCS 可能形成额外连接，需要人工检查。
- 改动布局后，手动筋可能失效，必须重新确认。

### 2.5 融合边界

“融合边界”使用多边形布尔并集合并 PCS、工艺边和连接筋，输出闭合外环与内部加工槽。

- 曲线离散弦高公差默认 0.001 mm，范围 0.000001–0.1 mm。
- 可附带 `PANEL_REFERENCE` 参考轮廓；参考线不应作为加工线。
- 数值计算不等于制造公差保证。
- 融合失败、自交或超预算不会输出伪成功结果。

### 2.6 图层、导出与文件安全

| 内容 | 图层 |
| --- | --- |
| 设计图 PCS | `PANEL_PCS` |
| 工艺边 | `PANEL_RAIL` |
| 连接筋 | `PANEL_BRIDGE` |
| 融合边界 | `PANEL_FUSED` |
| 融合参考 | `PANEL_REFERENCE` |
| 尺寸标注 | `PANEL_DIM_PCS` / `PANEL_DIM_ARRAY` / `PANEL_DIM_SET` |
| 目标尺寸参考框 | `PANEL_FRAME`（无工艺框时，不是实体材料） |

点击“生成新拼版图纸”：

- 结果在主窗口**新标签**打开；
- 新文档未保存，需要 `Ctrl+S`；
- 原图不修改；
- 输出是全新毫米文档，不携带被排除的文字、原尺寸块、不支持对象和布局。

导出：

- 可选 DXF、PDF、DWG，共用文件基名。
- DWG 需要 ODA；未配置时禁用。
- PDF 是 A4 适合页面，**非 1:1**。
- 覆盖已有文件会确认。
- 禁止使用原单板路径作为输出路径。
- 多个格式不是事务：某个失败时会列出已完成的文件。

## 3. SET → Panel 材料方案

### 3.1 当前 SET 自动参与

材料页不再是独立输入窗口：

- 拼版页每次成功重新生成 SET，当前 SET 会自动带入材料页。
- 当前 SET 始终作为第一个比较方案，名称显示为“当前 SET”。
- 自动搜索也只基于当前拼版确认的 PCS 外形。
- 没有真实 PCS 几何时，自动搜索不可用，只能比较手动尺寸。

### 3.2 材料输入

| 参数 | 说明 |
| --- | --- |
| 大料输入单位 | mm 或 inch；只换算输入，不缩放图纸 |
| 大料 X 宽 / Y 高 | 材料尺寸 |
| 附件示例按钮 | 填入 18.42″ × 24.42″ = 467.868 × 620.268 mm |
| 左 / 右 / 下 / 上预留 | 材料四边不可用区域 |
| 材料上 SET X / Y 净距 | SET 与 SET 之间的加工净距 |
| 允许 SET 旋转 90° | 材料有纹理 / 层压方向限制时关闭 |
| 比较 0°/90° 分区混排 | 左右或上下分区使用不同方向；有方向限制时关闭 |

有效工作区：

```text
工作区宽 = 大料宽 - 左预留 - 右预留
工作区高 = 大料高 - 下预留 - 上预留
```

所有 SET 必须：

- 在工作区内；
- 不重叠；
- 满足指定净距。

### 3.3 订单与出货

| 参数 | 说明 |
| --- | --- |
| 订单 PCS 数量 | 目标出货 |
| 已有大料张数 | 现有材料能出多少 |
| 预计良率 (%) | 用于估算，不是保证 |
| 出货规则 | 按 PCS 良率，或按整 SET 良率 |

- **按 PCS 良率**：允许零散 PCS 出货。
- **按整 SET 良率**：只能按完整 SET 交货，出货数必须是 `PCS/SET` 的整数倍。

### 3.4 手动比较 SET

表格列：

```text
方案 | SET X mm | SET Y mm | PCS/SET | PCS面积mm² | 左边mm | 右边mm | 下边mm | 上边mm
```

规则：

- 当前拼版 SET 会自动参与，不需要重复填写。
- **PCS 面积未知填 0**，结果显示“未知”，不会用矩形面积冒充真实单板面积。
- 边距是 **SET 工艺边**，不是大料预留。
- PCS/SET 必须是 1–100000 的整数。
- 修改表格或任何材料输入后，旧结果失效，必须重新计算。

软件会为每个 SET 尝试：

- 0° 规则排布；
- 90° 规则排布（允许时）；
- 实际包含两种方向的分区混排（勾选时）。

只有真正放得下的方案才显示。

结果排序可切换：

- 每大料 PCS 产出优先；
- 所需材料张数优先；
- SET 占料率优先；
- PCS 实际面积利用率优先。

### 3.5 自动搜索不同 PCS→SET

自动搜索需要当前 PCS 的真实闭合外形。参数：

| 参数 | 说明 |
| --- | --- |
| 搜索最大行数 / 列数 | 每 SET 内最多 8 × 8 |
| 每 SET 最少 / 最多 PCS | 默认 1–36，最大 64 |
| SET 最小 / 最大 X / Y | 工艺允许的 SET 尺寸范围 |
| 允许 PCS 在 SET 内转 90° | 关闭后只搜索原方向 |
| 搜索行 / 列 / 棋盘交替 180° 紧排 | 额外搜索交错候选 |

搜索行为：

- 搜索有限行列、0°/90°、交替行 / 列 / 棋盘 180° 步距组合。
- 每个候选都用真实几何验证重叠和净距。
- 预算：**512 个校验候选 / 45 秒**。
- 可取消；取消后旧结果不能继续当成当前结果导出。
- 修改任何输入都会让结果失效。
- 不是全局最优异形套排；不搜索任意角度、任意形状套排、多张不同规格材料联合优化。

### 3.6 结果列

| 列 | 含义 |
| --- | --- |
| SET/Panel | 每张大料放多少个 SET |
| PCS/Panel | 每张大料出多少 PCS = SET/Panel × PCS/SET |
| SET 占大料% | SET 矩形面积 / 整张大料面积 |
| SET 占工作区% | SET 矩形面积 / 扣除四边后的工作区面积 |
| PCS 实际占 SET% | PCS 真实面积 / SET 面积 |
| PCS 实际占大料% | PCS 真实面积 / 整张大料面积 |
| 所需材料张 | 满足订单的最少整数张数 |
| 预计出货 PCS | 按良率和出货规则估算 |
| 超交 PCS | 预计出货 − 订单 |
| 已有材料预计 PCS | 已有张数能出多少 |
| 相对基准 PCS/Panel | 与基准方案的产出差 |

**SET 占料率和 PCS 实际面积利用率不是一回事。**  
SET 占料率把 SET 当完整矩形；PCS 实际面积用真实闭合外轮廓。面积利用率高不一定件数更多，相同材料下通常先看 **PCS/Panel**。

### 3.7 公式

所有面积单位 mm²，百分比乘 100：

| 指标 | 公式 |
| --- | --- |
| 大料面积 | PanelX × PanelY |
| 工作区面积 | (PanelX − 左 − 右) × (PanelY − 下 − 上) |
| SET 面积 | SetX × SetY（含 SET 工艺边） |
| 去工艺边 SET 区域 | (SetX − SET左 − SET右) × (SetY − SET下 − SET上) |
| SET 占整张大料 | SET/Panel × SET面积 / 大料面积 |
| SET 占工作区 | SET/Panel × SET面积 / 工作区面积 |
| 去边 SET 占大料 | SET/Panel × 去边SET面积 / 大料面积 |
| PCS 真面积占 SET | PCS/SET × 单PCS真实面积 / SET面积 |
| PCS 真面积占去边 SET | PCS/SET × 单PCS真实面积 / 去边SET区域 |
| PCS 真面积占大料 | PCS/Panel × 单PCS真实面积 / 大料面积 |

产出与出货：

```text
PCS/Panel = SET/Panel × PCS/SET
已有材料毛产出 = 已有张数 × PCS/Panel
按 PCS 良率预计出货 = floor(张数 × PCS/Panel × 良率)
按整 SET 良率预计出货 = floor(张数 × SET/Panel × 良率) × PCS/SET
所需材料 = 满足预计出货 ≥ 订单的最少整数张数
预计超交 = 预计出货 − 订单
```

软件会再校验“前一张数量不足”，避免浮点取整差一张。订单为 0 时，所需张数和预计出货都为 0。

### 3.8 应用回拼版

只有带真实几何的方案才能“应用到 SET 拼版”。点击后会：

- 回填行列、旋转、固定 SET / 步距、交错和手动筋；
- 自动切回“拼版 SET”页；
- 重新生成 SET 和尺寸。

应用后必须重新检查：

- 行列数是否与方案一致；
- 工艺边、连接筋是否仍有效；
- 实际最小净距是否满足要求；
- SET 尺寸是否在工艺允许范围内。

自动搜索方案不会复用原手动连接筋，应用后需要重新确认。

### 3.9 预览与导出

“大料排布预览”：

- 默认显示 SET 外框、编号、工作区和大料尺寸。
- 勾选“显示真实 PCS 外形”后显示真实 PCS（仅几何来源方案）。
- 最多 2000 PCS / 200000 顶点；超过会拒绝。
- 会检查 PCS 不超出对应 SET。

导出：

| 格式 | 内容 |
| --- | --- |
| CSV | 方案计算表，UTF-8 BOM，Excel 打开中文正常；可用于独立复算 |
| PDF 报告 | 输入条件、结果表、基准变化量 |
| DXF | 大料排布图，原生输出 |
| PDF 图纸 | 大料排布图，适合页面，非 1:1 |
| DWG | 需要 ODA |

“生成大料排布图”会在主窗口新标签打开，不自动保存。

## 4. 数据口径：为什么不能照抄截图

附件示例大料 18.42 × 24.42 in = 467.868 × 620.268 mm，面积 290203.548624 mm²。

- 6 PCS/SET、107.20 × 194.41 mm：
  - 11 SET/Panel，SET 占整张大料约 **78.996%**；
  - 12 SET/Panel，约 **86.177%**。
  - 截图同时写 11 SET / 66 PCS 和 86.20%，说明它不是同一个“完整 SET 矩形占整张大料”口径。
- 4 PCS/SET、107.40 × 165.24 mm：
  - 16 SET/Panel 占整张大料约 **97.845%**。
  - 能否真的放 16 必须检查边距 / 间距；截图的 84.60% 可能扣了工艺边或采用其他面积口径。
- 新 SET 面积相对旧 SET 约 **−14.85%**；66 → 64 PCS 的产出变化是 **−3.03%**。

结论：软件按实际输入重新计算，不照抄附件数字。

真实搜索例子（测试条件）：

```text
大料 467.868 × 620.268 mm
四边各预留 10 mm
SET 间距 2 mm
订单 5000 PCS
预计良率 96%
```

搜索到一个 6 PCS/SET 的混排候选：

```text
2×3 PCS，0°，交替行 180° 紧排
SET 约 209.900 × 45.695 mm
25 SET/Panel
150 PCS/Panel
SET 占大料约 82.63%
35 张大料
预计出货 5040 PCS
```

这只是一组参数下**已验证可行**的候选，不是批准的生产规格，也不是全局最优结论。

## 5. 当前边界

- 仅软板二维几何及数量规划。
- 不包含硬板 V-cut、铣边补偿、叠板、铜层、层压、补强方向、强度规则。
- 不生成 Gerber / Excellon 生产文件。
- 拼版和材料搜索都是有限候选比较，不承诺全局最优。
- 材料上只比较规则网格、整体 90°、左右 / 上下两种矩形分区。
- 不搜索任意角度、任意形状 SET、无限层级切分、整张材料自动开料、多规格材料联合优化。
- 预计出货是估算，不是保证。
- PDF 是适合页面输出，不是 1:1。
- 自动筋、融合边界、间距检查都需要工程复核。
- 原图、拼版图、材料图应分别保存并保留版本记录。

- `fpc_material` 测试覆盖 SET/PCS 利用率、未知面积、混排、净距、搜索预算、CSV/PDF/DXF 输出。
- `ui` 测试覆盖合并窗口、材料页自动比较、后台搜索、取消、应用回 SET、生成大料图、原图隔离。
- 独立审计脚本 `tests/native/PanelizationInterop.py` 和 `tests/native/FpcMaterialInterop.py` 用 ezdxf 和独立算术复算，检查几何范围与 CSV 公式。
- 可通过 `CAD_TEST_PANEL_SOURCE` 指定 E2 原图运行真实样本测试；测试夹具不代表批准制造版本。
