# DWG 技术要求横向展开问题

## 原因与修复

生产图纸中的 MTEXT 同时使用 `^J`、`\P` 分段，并设置文字栏宽。旧解析器未识别 `^J`，旧画布未使用栏宽自动折行，文字估算边界也与实际绘制不一致。长段文字因此横向展开，“显示全部”把图框缩小。

- `src/io/DxfAdapter.cpp`：拼接 MTEXT 原始字节后解码，支持跨组码的 Unicode 转义；解析 caret 换行、栏宽和行距；保留源记录与只读约束。
- `src/core/TextLayout.cpp`：使用 Qt 文字排版和字体字形轮廓，按栏宽折行；绘制、文字边界、空间索引、选择和显示全部使用相同几何。
- 块缩放同步缩放文字栏宽，避免嵌套块内文字换行变化。
- 默认二维平面判断允许 `1e-9` 内的数值噪声，不投影真正非零 Z 的对象。
