# 0.2.4 自动恢复与文件安全

## 本轮新增

- 独立 `RecoveryManager`：60 秒检查周期，按文档版本跳过未变化的数据，串行后台原子写入，SHA-256 校验，256 MiB DXF 数据上限。
- 启动恢复列表、恢复选中、稍后处理和二次确认丢弃；未命名和多个文档均可恢复。恢复清空保存路径并保留未保存状态，不自动覆盖原图。
- 每个程序实例独立锁与会话目录；异常进程退出留下的快照可恢复，活动实例不参与恢复。
- 正常保存、放弃修改、取消关闭以及后台结果迟到的生命周期处理；恢复旧快照在新副本快照成功提交前保留。
- 修复 DXF 无修改重存时 `$HANDSEED` 递增的问题；扫描传统 VERTEX/SEQEND 句柄和 DIMSTYLE 的组码 105，避免新增对象句柄碰撞。
- 保留并验证工作区已有的文字排版/外部标注文字编辑修改，没有回退这些修改。

## 验证方式

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-native.ps1
.\.venv\Scripts\python.exe tests/native/DxfInterop.py build/native/bin/CAD.exe
.\.venv\Scripts\python.exe tests/native/DxfSafetyInterop.py build/native/bin/cad_dxf_safety_probe.exe
```

原生测试包括核心、界面、自动恢复、性能冒烟四组。恢复专项测试使用独立进程 `_Exit` 模拟不执行析构的退出，验证残留锁；覆盖 50,000 图元快照、未命名/多文档、写入失败保留旧快照、损坏头/截断内容、路径限制、保存/撤销/关闭和后台快照交错。界面覆盖恢复入口、损坏文件延后/丢弃、取消整窗口退出、单标签清理，以及后台保存期间继续编辑和保存失败。

独立脚本生成两个共享图形块的外部标注，验证只修改一个标注的公差；检查样式、箭头、定义点、原始共享块、扩展属性与其他对象不变。原始、编辑、恢复 DXF 要求零审计错误与零修复，原图哈希不变，编辑/恢复输出字节一致。

## 使用边界

- 这是编辑成果恢复，不是备份、自动保存到原图或无损 DWG 归档。
- 60 秒是检查周期，不保证最多丢失 60 秒：排队、大图耗时和写入失败会增加间隔。尚未提交成功的快照无法恢复。
- 不恢复撤销历史、视口、选择或测量面板记录；源对象保留能力沿用现有 DXF 适配器。
- 文档恢复解析和恢复列表扫描目前在界面线程；大快照恢复可能需要等待。定时写入在后台。
- 恢复快照不自动过期，需在恢复列表中明确丢弃；包含图纸内容，请按图纸安全要求管理当前用户的本地应用数据目录。
- Windows 使用 `%LOCALAPPDATA%\EngineeringTools\CAD\recovery`，使用“文件 → 恢复未保存图纸…”可在没有快照时查看实际目录。

0.2.4 使用独立的单文件便携解压目录，避免复用已有 0.2.3 程序；发布包不包含开发测试程序。
