# CAD · Qiao 使用教程

> 适用版本：**0.3.0**  
> 教程版本：**v0.2（按合并后的“拼版”窗口重写）**  
> 目标：从打开一张 FPC 原图，到拼 SET、算大料、出报告，按步骤走完；同时说明软件为什么这样判断、哪些结果不能直接当成生产结论。

---

## 0. 先看这一页：软件怎么分工

本软件处理的是 **二维几何与数量规划**，不是电路设计软件，也不是 CAM 制造文件生成器。

核心层级只有三层：

```text
PCS / Unit（单件）
   ↓ 拼版
SET（交货拼版，含工艺边、连接筋）
   ↓ 排大料
Panel（材料大料 / 开料张）
```

- **PCS**：一张软板单件的外形。
- **SET**：把多个 PCS 排在一起，形成交货拼版；可以带工艺边和连接筋。
- **Panel**：一张材料大料上能放多少个 SET。

### 0.1 0.3.0 的界面变化

0.2.9 及以前，“拼版”和“软板材料方案”是两个窗口。0.3.0 起合并成**一个“拼版”窗口**：

| 位置 | 内容 |
| --- | --- |
| 菜单 | **工程分析 → 拼版**（不再有“软板材料方案”菜单项） |
| 工具栏 | **拼版**（不再有“软板材料方案”按钮） |
| 命令 | `PANEL` / `PANELARRAY`；旧命令 `FPCPLAN` / `MATERIAL` 也打开同一个窗口 |
| 窗口顶部 | 两个页签：**拼版 SET**、**材料方案 / 利用率** |
| 拼版 SET 页内 | **原图外轮廓选择**、**拼版预览 / 连接筋** |
| 材料页内 | **方案与产出比较**、**大料排布预览** |

窗口标题为 **“拼版 · 单 PCS → ARRAY → SET”**。

材料页不是独立窗口：当前 SET 会自动成为第一个比较方案。你不需要先关掉拼版窗口，也不需要再找材料入口。

### 0.2 建议顺序

```text
确认 PCS 外形 → 做 SET → 再做材料方案 → 应用回 SET → 出图
```

不要在 PCS 外形还没确认时直接拿一个矩形尺寸去算材料，否则后面的利用率和出货都只是“矩形估算”。

### 0.3 五分钟跑通一次

1. `Ctrl+O` 打开一张单板 DXF。
2. 在画布上框选**单个 PCS 的外形区域**。
3. 工具栏点“拼版”，等自动识别出轮廓和 2 × 2 预览。
4. 在右侧设置行数、列数、X/Y 净距、四边预留。
5. 看底部 `PCS / ARRAY / SET` 三组尺寸和“实际最小净距”。
6. 点“生成新拼版图纸”，在主窗口新标签查看结果。
7. `Ctrl+S` 保存拼版图。
8. 回到拼版窗口，切到顶部的**材料方案 / 利用率**页。
9. 输入大料尺寸、四边预留、订单、良率，点“计算 / 比较 SET 方案”。
10. 选择方案，看 `SET/Panel`、`PCS/Panel`、所需材料张数和预计出货。
11. 需要出图时点“生成大料排布图”或“导出”。
12. 选中更优方案，点“应用到 SET 拼版”，回拼版页重新生成工艺边 / 连接筋。

跑通后再看后面的参数解释和边界说明。

## 1. 安装、启动与界面

### 1.1 三种运行方式

| 文件 | 用途 |
| --- | --- |
| `dist\CAD-0.3.0.exe` | 单文件便携版，双击运行；首次会解压运行库到 `%LOCALAPPDATA%\Qiao\CAD-Portable\0.3.0` |
| `dist\CAD-0.3.0-Setup.exe` | 安装包，创建桌面 / 开始菜单快捷方式 |
| `dist\CAD-0.3.0-Windows-x64.zip` | 便携压缩包，**完整解压**后运行 `CAD\CAD.exe` |

注意：

- 便携 ZIP 不能只复制 `CAD.exe`，必须保留同目录 DLL 和 `platforms` 文件夹。
- 版本升级使用独立目录，不会复用旧版本程序。
- 运行程序不需要安装 Python 或 Qt。

### 1.2 第一次启动

启动后默认是**空白图纸**，不会自动打开演示板。

首次启动可能出现两个窗口：

1. **操作教程 / 快速上手**：可以取消勾选“启动时显示本教程”；以后从“帮助 → 操作教程 / 快速上手”重新打开。
2. **恢复未保存图纸**：如果上次异常退出且留下了恢复快照，会提示恢复。没有快照就不会出现。

需要 PCB 示例时，用“文件 → 打开演示板”。

## 2. 图纸、单位与坐标：先避免“看起来对，实际错”

### 2.1 单位不是缩放

“文件 → 设置单位”只改变**单位声明**和 mm / mil 换算显示，**不会缩放图形坐标**。

- DXF 的 `$INSUNITS` 声明了单位时，按声明换算。
- 没有声明单位时，软件按 **1 图形单位 = 1 mm** 处理，并在面板和命令区提示。
- 1 mil = 0.0254 mm。

所以打开外部图纸后，第一件事是确认：

1. 图纸实际单位是什么？
2. 软件当前单位是什么？
3. 图上标注的 100 是 100 mm、100 mil，还是别的？

**单位错了，后面的拼版尺寸、间距、材料利用率全部会错。**

### 2.2 坐标与精确输入

模型坐标 `double`，Y 轴向上。命令栏支持：

| 输入 | 含义 |
| --- | --- |
| `10,20` | 绝对坐标 X=10，Y=20 |
| `@5,0` | 相对上一点 X+5，Y+0 |
| `20<45` | 相对上一点，距离 20，角度 45° |
| `20` | 沿当前光标方向输入长度 20 |

角度单位是度，逆时针为正。

### 2.3 单击对象看属性

单击图形后，右侧“对象属性”显示：

- 类型、图层、颜色、线宽
- 点坐标、半径、文字内容、文字高度等
- 长度、面积、周长等几何属性

双击属性表可以进入编辑；多选时可批量改图层 / 颜色。

## 3. 视图与选择

### 3.1 导航

| 操作 | 功能 |
| --- | --- |
| 滚轮 | 围绕鼠标位置缩放 |
| 中键拖动 | 平移 |
| `Home` | 显示全部 |
| 画布方向键 | 移动图纸；`Shift` 加速，`Ctrl` 微调 |
| `+` / `-` | 放大 / 缩小 |
| 视图 → 框选缩放 | 拖矩形放大指定区域 |
| 视图 → 居中选中对象 | 快速定位选中对象 |

方向键只有在**画布获得焦点**时才移动图纸；光标在命令栏时，方向键仍然移动文字光标。

### 3.2 选择规则

- 单击：选择对象。
- `Shift` + 单击：加选 / 减选。
- **左 → 右**拖框：窗口选择，只选**完全包含**的对象。
- **右 → 左**拖框：交叉选择，**碰到就选**。
- `Ctrl+A`：选择所有可见图层对象。
- `Esc`：结束当前工具，回到选择状态。

0.2.8 起修复了白色水平 / 竖直图框因零宽高包围盒导致框选失效的问题；只读白色文字的空隙也可以点击选择。

### 3.3 隐藏与锁定

- **隐藏图层**：不显示，也不参与按图层分析。
- **锁定图层**：可见、可选择、可测量，但**不能编辑或删除**。

“网格 / 坐标轴”属于视图，不是可删除实体。用 `F7` 关闭网格。

## 4. 打开、保存与导出

### 4.1 打开

“文件 → 打开 DXF / DWG”或 `Ctrl+O`。

- DXF：原生 ASCII 读取。
- DWG：优先使用已配置的 ODA File Converter；没有 ODA 时自动调用随包内置的 GNU LibreDWG 读取。
- 大文件在后台读取，可取消。
- 读取失败会明确报错，不会偷偷改读同名 DXF。

### 4.2 支持范围（二维）

**可显示 / 编辑：**

- `LINE`
- `LWPOLYLINE`、传统 `POLYLINE/VERTEX/SEQEND`
- `CIRCLE`、`ARC`、`ELLIPSE`
- 基本左对齐 `TEXT`
- 本软件创建的对齐 `DIMENSION`
- 由上述对象组成的 `INSERT` 块展开

**只读预览：**

- 二维实心 `HATCH`
- `SOLID` / `TRACE`
- 1–8 次二维 `SPLINE`
- 外部 `MTEXT`、部分外部 `DIMENSION`
- 不支持的块内容会尽量部分显示

**当前不完全支持：**

- 图案填充、边线式 HATCH
- 部分周期 / 拟合 SPLINE
- 非等比缩放曲线
- 无可用图形块的标注
- 布局空间、3D、非默认 OCS 对象

不支持的源记录会**保留在 DXF 中**，但可能不显示。打开后看命令区提示，不要假设“没显示 = 文件里没有”。

### 4.3 保存

- `Ctrl+S` 保存，`Ctrl+Shift+S` 另存为。
- 新文档保存为 R2010 ASCII DXF。
- 保存使用原子写入，失败不会截断原文件。
- **保存 DWG 需要 ODA**。没有 ODA 时，普通保存会进入 DXF 另存为，保留原 DWG。
- 新文字限定为单行 `TEXT`；含换行的文字不能保存。

### 4.4 导出 PDF

“文件 → 导出 PDF”。

- A4 适合页面，**不是 1:1 工程比例**。
- 不包含网格、光标、选择高亮。
- 拼版窗口和材料页另有自己的 PDF 输出。

### 4.5 文件安全规则

- 拼版结果、材料排布图都是**新文档**，不会自动覆盖原单板。
- 拼版窗口导出时，如果输出路径等于原单板路径，会拒绝。
- 材料方案生成的大料图需要你 `Ctrl+S` 另存，不会自动保存。
- 原图仍然建议保留备份；DWG 转换 / 保存不保证无损。

## 5. 绘图

### 5.1 工具与命令

工具栏或命令栏输入：

| 命令 | 别名 | 功能 |
| --- | --- | --- |
| `LINE` | `L` | 直线 |
| `PLINE` | `PL` | 多段线 |
| `RECTANG` | `REC` | 矩形 |
| `CIRCLE` | `C` | 圆 |
| `ARC` | — | 圆弧（圆心 → 起点 → 终点，逆时针） |
| `ELLIPSE` | — | 椭圆（圆心 → 长轴端点 → 短轴点） |
| `TEXT` | — | 单行文字 |

多段线：

- `Enter` 完成。
- 输入 `C` 闭合（画多段线时）。
- `Esc` 返回选择。

### 5.2 捕捉与辅助

| 快捷键 | 功能 |
| --- | --- |
| `F3` | 对象捕捉：端点、中点、圆心、象限点、交点、垂足 |
| `F8` | 正交 |
| `F10` | 45° 极轴 |
| `F7` | 网格 |

正交和极轴互斥：打开一个会自动关闭另一个。

### 5.3 小练习：画一个 30 × 20 的板框

1. 命令栏输入 `REC`。
2. 输入 `0,0`。
3. 输入 `@30,20`。
4. 单击矩形，右侧属性确认宽度 30、高度 20。
5. 命令栏输入 `AREA`，查看面积 600、周长 100。

## 6. 编辑

### 6.1 常用编辑

| 命令 | 说明 |
| --- | --- |
| `MOVE / M` | 移动 |
| `COPY / CO` | 复制 |
| `MIRROR / MI` | 镜像，**保留原对象** |
| `ROTATE / RO` | 绕指定中心旋转 |
| `ARRAY` | 矩形阵列 |
| `OFFSET / O` | 偏移；直线向左，圆 / 凸闭合轮廓外扩 |
| `TRIM / TR` | 修剪两条直线之一 |
| `EXTEND / EX` | 延伸两条直线之一 |
| `EXPLODE / X` | 分解矩形 / 多段线 |
| `JOIN / J` | 合并同图层、端点连续的直线 |
| `ERASE / E` 或 `Delete` | 删除选中 |

### 6.2 删除的边界

- 锁定图层不能删除。
- 从 0.2.7 起，外部尺寸、只读文字 / 填充预览也可以删除。
- 选中外部标注的一部分，会删除**完整标注**。
- 选中只读块的一部分，会删除**完整块实例**，不影响其他引用。
- 删除后保存重开仍然不存在；`Ctrl+Z` 可撤销。

“删除选中”按钮在工具栏和“编辑”菜单里都有。

### 6.3 清理重复对象

“工程分析 → 清理重复对象”。

软件只在以下条件**全部相同**时判为重复：

- 几何完全一致
- 图层相同
- 颜色状态相同
- 常宽 / 分段宽度相同
- 源记录属性相同

清理时保留每组中 **ID 最小**的对象，删除其余可编辑对象。锁定对象不会被删。

这不是“看起来重合就删”，所以不会误删同位置但不同属性的对象。

### 6.4 撤销 / 恢复

- `Ctrl+Z` 撤销，`Ctrl+Y` 恢复。
- 每个文档独立，最多保留 100 个操作。
- 保存点之后的修改可以用 `*` 在标签上识别。

### 6.5 编辑文字与公差

双击文字 / 标注文字，或选中后：

- `Ctrl+E`
- 工具栏“编辑文字 / 标注”
- 右侧“对象属性”里的按钮

规则：

- `<>` 表示实测值占位符。
- `<>%%P0.1`：保留实测数字，公差改为 ±0.1。
- `120.00±0.1`：使用固定显示文字。
- `%%P` / `%%p` 显示为 `±`；`%%D` 显示 `°`；`%%C` 显示 `Ø`。

限制：

- 外部标注只支持可安全识别的单行文字。
- 只改显示文字，不改变板框、尺寸线、箭头或实测尺寸。
- 复杂格式、嵌套标注、锁定图层仍只读。
- 编辑后建议 `Ctrl+Shift+S` 另存副本，再重新打开检查。

## 7. 测量与标注

### 7.1 测量工具

| 工具 | 说明 |
| --- | --- |
| 距离 `DI / DIST` | 两点距离 |
| 水平距离 | 水平方向距离 |
| 垂直距离 | 垂直方向距离 |
| 连续测量 | 连续多点 |
| 角度 `ANGLE` | 三点夹角 |
| 坐标 `ID` | 光标坐标 |
| 对象间距 `GAP / MEASURE` | 两个对象之间的真实间距 |
| 对齐标注 `DIM / DIMALIGNED` | 创建对齐线性标注 |

### 7.2 对象间距 `GAP`

操作：依次单击两个对象。

计算规则：

- 直线：中心线到中心线。
- 带线宽走线：垂直逼近时计入半线宽，按边到边。
- 圆 / 圆弧：边到边。
- 闭合对象 / 包含关系：间距为 0。

结果：

- 左侧“标注测量”面板实时显示。
- 同时在图纸上生成一条标注，随 DXF 保存。
- 标注字高默认随间距自适应；选中后可在属性里改“标注字高”。

### 7.3 mm / mil 双单位

- 测量面板、状态栏坐标、间距标注都按 mm / mil 双单位显示。
- 1 mil = 0.0254 mm。
- 可用“视图 → 设置坐标原点”把当前光标设为原点；“重置坐标原点”恢复 (0,0)。

### 7.4 标注编辑

对齐标注生成后是普通 DXF `DIMENSION` 加图形块。可以：

- 选择、移动、删除。
- 编辑文字 / 公差。
- 保存重开保留毫米格式、小数位和字高。

注意：**编辑文字不是修改模型尺寸**。用固定数字覆盖显示，不会改变几何。

## 8. 图层管理

右侧“图层管理”：

- 新增图层。
- 删除图层：只能删空层，且源文件块 / 布局 / 未支持对象不能仍引用它；默认图层 `0` 不能删。

## 9. PCB / FPC 工程分析

### 9.1 分析范围

所有分析都遵循：

> **有选区时优先用选区；没有选区时用左侧指定图层；选择“全部可见图层”时用全部可见对象。**

因此，按图层检查前建议先 `Esc` 清除选择，避免误用上一次选区。

### 9.2 六种分析

| 分析 | 选择要求 | 输出 |
| --- | --- | --- |
| 板框 | 只选 **一个闭合板框** | 包围宽、包围高、面积、周长 |
| 孔径 | 圆对象 | 按直径分组，显示孔径 + 数量 |
| 间距 | 至少两个对象；输入最小要求 | 小于要求的对象对，按间距升序 |
| 焊盘 | 闭合对象；输入最小宽 / 高 | 小于要求尺寸的焊盘 |
| 工艺边 | 一个闭合板框 + 输入最小距离 | 距板边不足，或板框外对象 |
| 重复 | 线 / 圆 / 多段线 / 矩形 | 完全重复的图形组 |

补充规则：

- 孔径只统计 `CIRCLE`，不会把圆自动解释成真实钻孔。
- 焊盘只检查闭合形状；圆按直径，矩形按边长，其他按包围盒。
- 间距 / 工艺边把闭合对象当实心区域，包含 / 重叠为 0。
- 分析排除文字、标注、HATCH、样条预览。
- 曲线离散目标误差 0.005 图形单位；超过分段预算会停止并报告误差上界。
- 间距结果超过 100000 条会拒绝，需要缩小范围。
- 不包含网络、线宽、铜厚、阻焊、叠层、镀孔类型。

### 9.3 结果使用

- 分析在后台执行。
- 完成后结果列表显示；单击结果会选中并居中相关对象。
- 如果检查期间文档或当前标签变化，旧结果会被忽略，不会显示过期结论。

### 9.4 演示板流程

1. “文件 → 打开演示板”。
2. 清除选择。
3. 左侧范围选择 `BOARD`，执行“板框分析”。
4. 范围选择 `DRILL`，执行“孔径分析”，应看到 Ø3.2 × 4。
5. 范围选择 `PAD`，执行“焊盘分析”。
6. 选择单个板框，执行“工艺边分析”。

演示板尺寸为 80 × 50 mm，四个 Ø3.2 mm 孔，2 × 3 mm 焊盘。

## 10. 拼版窗口：PCS → SET

### 10.1 先理解三个尺寸

| 尺寸 | 含义 |
| --- | --- |
| **PCS** | 第一块放置后单板外形的 X/Y 长宽；90° 旋转后交换 |
| **ARRAY** | 所有放置 PCS 的真实几何外接矩形，不含文字、箭头、线宽、工艺边、连接筋 |
| **SET** | 含四边预留的整版目标长宽 |

软件用真实几何和定义点生成尺寸，画布、PDF、DXF 标注共用同一套布局。

**生成后的拼版是普通实体，不是参数化模型。** 手动移动 PCS 后，旧尺寸不会自动跟着变，需要重新生成。

### 10.2 准备原图

1. 打开**正确的单板原图**。
2. 检查是否有旧版重叠轮廓、图框、说明文字、尺寸线。
3. 最佳做法：先在主画布框选单板区域，再打开拼版窗口。
4. 不要把整张工程图、多个视图、旧版外形一起选进去。

注意：参考文件 `set.dxf` 不是有效模板；示例请用原始 E2 DXF 和红版 `E2-FPC-PANLE-20261124.dxf` 做对照。

### 10.3 打开与自动识别

入口：

- “工程分析 → 拼版”
- 工具栏“拼版”
- 命令 `PANEL` / `PANELARRAY`
- 旧命令 `FPCPLAN` / `MATERIAL`（同样打开本窗口）

打开后：

- 有选区：自动识别选区。
- 无选区：识别当前可见图形。
- 自动排除文字、外部标注、悬挂线。
- 闭合外形候选按面积排序。
- 默认自动预览 2 × 2。
- 可点“自动拼版（识别所选区域 / 当前图）”重新识别。

如果图里包含图框或多个视图，**先框选单板区域**，否则自动识别可能把整张图当成一个区域。

### 10.4 手动确认外轮廓

自动识别不放心时：

1. 在“原图外轮廓选择”页选择准确外形线。
2. 支持分段 `LINE`、`ARC`、`LWPOLYLINE`、传统 `POLYLINE`、`CIRCLE`。
3. 点“确认选中轮廓（支持分段直线 / 圆弧）”。
4. 看“已确认外轮廓”下拉框中的尺寸和面积。

规则：

- 多条独立闭合轮廓会作为候选，不自动把孔加入模板。
- 有断口 / 分叉时，界面显示问题端点坐标；取消错误边、补齐后重新确认。
- 颜色不是版本判据，软件不猜“哪个是修改版”。
- 同长宽但不同凹口的候选必须人工确认。
- 自动区域合并产生的折线近似会标“折线近似”；手动准确选边优先保留圆弧。

“原图外轮廓选择”页还有：

- **删除选中内容（仅此副本）**：只清理拼版窗口里的原图副本，不改主文档。
- **撤销清理**：撤销副本里的删除。

### 10.5 拼版参数

“拼版预览 / 连接筋”页右侧：

| 参数 | 说明 |
| --- | --- |
| 整体旋转 | 0° / 90° / 180° / 270°，只旋转，不镜像 |
| 行数 / 列数 | 每行 / 每列放几个 PCS |
| 固定 SET / 大板尺寸 | 勾选后使用指定 SET 宽高，余量居中 |
| 自动计算数量 | 按 SET 尺寸反算行列；**不是最优排料**，会禁用行列输入 |
| SET 宽 X / 高 Y | 固定 SET 时的目标尺寸 |
| 使用步距（交错紧排） | 勾选后 X/Y 输入变成相邻基点步距，而不是外接框净距 |
| X / Y 外接框净距 / 步距 | 普通模式是净距；步距模式是 ΔX / ΔY |
| 隔行旋转 180° | 相邻行旋转 180°，非镜像 |
| 隔列旋转 180° | 相邻列旋转 180°，非镜像 |
| 隔行 X 偏移 | 交错排布时的水平偏移 |
| 真实轮廓最小净距 | 按真实直线 / 圆弧检查的最小间距 |
| 左 / 右 / 下 / 上预留 | SET 四边预留 |
| 整体四边工艺框架 | 生成四条材料边，不是实心矩形 |
| 工艺边宽 | 框架宽度 |
| PCS 到工艺边最小净距 | PCS 与框架之间的距离要求 |
| 自动建议筋 | 自动生成邻近 PCS / 工艺边之间的最短连通建议 |
| 新连接筋宽 | 自动 / 手动筋宽度 |
| 手动筋表 | 起 X、起 Y、终 X、终 Y、筋宽；坐标是 SET 内绝对 mm |
| 连接 / 融合弦高公差 | 默认 0.001 mm，范围 0.000001–0.1 mm |
| 尺寸小数位 | 0–6 位 |
| 图纸内容 | 设计图（PCS + 工艺边 + 连接筋）或融合边界 |
| 长宽标注 | 是否输出 PCS / ARRAY / SET 标注 |
| 融合图附带 PCS 参考轮廓 | 仅融合图使用；参考线不应作为加工线 |

### 10.6 净距和步距的区别

这是最容易出错的地方：

- **普通模式**：X/Y 是两块 PCS **外接矩形之间**的净距；步距 = PCS 宽/高 + 净距。
- **步距模式**：X/Y 直接是相邻列 / 行**基点之间的 ΔX / ΔY**。

软件在两种模式下都会：

- 按闭合外形区域检查重叠 / 包含。
- 按真实直线和圆弧检查最小净距。

**不会只用包围盒距离代替最终净距。**

### 10.7 看预览和警告

底部状态栏会显示：

```text
PCS 宽 × 高 | ARRAY 宽 × 高 | SET 宽 × 高 | 行 × 列 = N PCS
实际最小净距 ... mm | PCS 面积利用率 ...%
```

还可能显示：

- 未连到工艺框的 PCS。
- 自动筋只是几何建议。
- 参数无效 / 超预算 / 轮廓未确认。

### 10.8 连接筋

连接筋用于把 PCS 和工艺边连起来，但软件**不校核强度、铜层禁布、鼠咬孔、V-cut**。

流程：

1. 勾选“自动建议筋（需工程确认）”，先看建议。
2. 点“建议筋 → 手动编辑”转成表格。
3. 在表格里调整端点 / 筋宽或删除。
4. 或点“手动筋：点两端”，在预览里点起点和终点。

注意：

- 坐标是 SET 内绝对毫米坐标，不是 PCS 本地坐标。
- 连接筋必须实际接触两个材料区域才有效。
- 连接筋越过其他 PCS 可能形成额外连接，需要人工检查。
- 改动布局后，手动筋可能失效，必须重新确认。

### 10.9 生成与导出

点“生成新拼版图纸”：

- 结果在主窗口**新标签**打开。
- 标题类似“PCB-FPC 拼版”。
- 新文档未保存，需要 `Ctrl+S`。
- 原图不修改。
- 输出是全新毫米文档，不携带被排除的文字、原尺寸块、不支持对象和布局。

“导出所选格式 / 内容…”：

- 可选 DXF、PDF、DWG。
- 多个格式共用文件基名。
- DWG 需要 ODA；未配置时禁用。
- PDF 是 A4 适合页面，**非 1:1**。
- 覆盖已有文件会确认。
- 禁止使用原单板路径作为输出路径。
- 多个格式不是事务：某个失败时会列出已完成的文件。

图层：

- 设计图：`PANEL_PCS`、`PANEL_RAIL`、`PANEL_BRIDGE`
- 融合图：`PANEL_FUSED`，可选 `PANEL_REFERENCE`
- 标注：`PANEL_DIM_PCS`、`PANEL_DIM_ARRAY`、`PANEL_DIM_SET`
- 无工艺框时：`PANEL_FRAME` 是目标尺寸参考框，不是实体材料

### 10.10 输出后核对清单

- [ ] PCS 宽高是否等于单板实际外形？
- [ ] ARRAY 是否覆盖所有 PCS，且不含文字 / 尺寸线？
- [ ] SET 是否等于 ARRAY + 四边预留？
- [ ] 行列数 × 单 PCS 数是否等于实际 PCS 数量？
- [ ] 实际最小净距是否 ≥ 工艺要求？
- [ ] 是否有 PCS 未连到工艺框？
- [ ] 连接筋是否碰到其他 PCS？
- [ ] 融合边界是否闭合、是否出现意外内部槽？
- [ ] 导出的 DXF 用另一款 CAD 打开是否正常？
- [ ] PDF 是否只是示意，不是 1:1？

### 10.11 当前边界

- 最多 400 PCS；行列各最多 100。
- 只有平移和 0/90/180/270° 旋转，禁止镜像和缩放。
- 固定 SET 是“扣除四边预留后放得下多少”，余量居中，不是任意角度最优排料。
- 自动筋不校核加工可行性。
- 融合是几何布尔，不是制造公差保证。
- 生成后没有关联式参数拼版。

**参考拼版不等于规则网格。** 红版 `E2-FPC-PANLE-20261124.dxf` 是 120 × 150 mm、10 PCS 的交错排布；同一单板按规则网格可能只得到 8 PCS。参考文件包含实际生产排法，不能把“10 PCS”当成固定模板直接套到别的参数上，也不能反过来假设规则网格一定能复现它。应以真实外形、净距和工艺条件重新计算。

## 11. 同一个窗口里的材料方案：SET → Panel

### 11.1 入口与自动带入

切到窗口顶部的 **材料方案 / 利用率** 页即可，没有单独的材料窗口。

首次切换到材料页时，软件会自动比较一次当前 SET。当前 SET 会显示为：

```text
当前拼版 SET：宽 × 高 mm，N PCS/SET，单 PCS 面积 ... mm²，SET 工艺边 左/右/下/上 ... mm。
```

- 当前 SET 自动作为第一个比较方案，名称“当前 SET”。
- 当前 SET 带真实 PCS 外形时，自动搜索按钮可用。
- 当前 SET 没有真实几何时，只能比较已有尺寸，不能搜索不同 PCS→SET 拼法。
- 拼版页改了行列、旋转、净距等参数并成功重新生成后，材料页会收到新的 SET，并提示重新计算。

旧命令 `FPCPLAN` / `MATERIAL` 也打开本窗口；它会先按当前选区 / 可见图识别 PCS，再进入拼版页。确认 SET 后切到材料页即可。

### 11.2 材料输入

#### 材料

| 参数 | 说明 |
| --- | --- |
| 大料输入单位 | mm 或 inch；只换算输入，不缩放图纸 |
| 大料 X 宽 / Y 高 | 材料尺寸 |
| 附件示例 18.42″ × 24.42″ | 填入 467.868 × 620.268 mm |
| 左 / 右 / 下 / 上预留 | 材料四边不可用区域 |
| 材料上 SET X / Y 净距 | SET 与 SET 之间的加工净距 |
| 允许 SET 旋转 90° | 材料有纹理 / 层压方向限制时关闭 |
| 比较 0°/90° 分区混排 | 左右或上下分区使用不同方向；有方向限制时关闭 |

有效工作区：

```text
工作区宽 = 大料宽 - 左预留 - 右预留
工作区高 = 大料高 - 下预留 - 上预留
```

所有 SET 必须：

- 在工作区内；
- 不重叠；
- 满足指定净距。

#### 订单与出货

| 参数 | 说明 |
| --- | --- |
| 订单 PCS 数量 | 目标出货 |
| 已有大料张数 | 用来算现有材料能出多少 |
| 预计良率 (%) | 用于估算，不是保证 |
| 出货规则 | 按 PCS 良率，或按整 SET 良率 |

出货规则区别：

- **按 PCS 良率**：允许零散 PCS 出货。
- **按整 SET 良率**：只能按完整 SET 交货，出货数必须是 `PCS/SET` 的整数倍。

#### 自动搜索

| 参数 | 说明 |
| --- | --- |
| 搜索最大行数 / 列数 | 每 SET 内最多 8 × 8 |
| 每 SET 最少 / 最多 PCS | 默认 1–36，最大 64 |
| SET 最小 / 最大 X / Y | 工艺允许的 SET 尺寸范围 |
| 允许 PCS 在 SET 内转 90° | 关闭后只搜索原方向 |
| 搜索行 / 列 / 棋盘交替 180° 紧排 | 额外搜索交错候选 |

### 11.3 手动比较 SET 表

“方案与产出比较”页的表格列：

```text
方案 | SET X mm | SET Y mm | PCS/SET | PCS面积mm² | 左边mm | 右边mm | 下边mm | 上边mm
```

规则：

- 当前拼版 SET 自动参与比较，**不需要重复填写**。
- **PCS 面积未知填 0**，结果显示“未知”，不会用矩形面积冒充。
- 边距是 **SET 工艺边**，不是大料预留。
- PCS/SET 必须是 1–100000 的整数。
- 可以“增加比较 SET”“删除选中 SET”。
- 修改表格后旧结果失效，需要重新计算。

切换材料页时，软件会自动比较一次；之后修改任何输入，都必须点“计算 / 比较 SET 方案”。

### 11.4 计算 / 比较 SET 方案

点“计算 / 比较 SET 方案”。

软件会为每个 SET 尝试：

- 0° 规则排布；
- 90° 规则排布（允许时）；
- 实际包含两种方向的分区混排（勾选时）。

只有**真正放得下**的方案才显示：

- 所有 SET 在工作区内；
- 不重叠；
- 满足净距。

结果默认按“每大料 PCS 产出优先”排序，可切换：

- 所需材料张数优先；
- SET 占料率优先；
- PCS 实际面积利用率优先。

### 11.5 后台搜索不同 PCS→SET

只有带入真实 PCS 外形时，搜索按钮才可用。

点“搜索不同 PCS→SET 拼法（后台）”后：

- 搜索不同行列、0°/90°、交替行 / 列 / 棋盘 180° 紧排。
- 每个候选都用真实几何验证重叠和净距。
- 预算：**512 个校验候选 / 45 秒**。
- 可取消。
- 取消后的旧结果不能继续当成当前结果导出。
- 修改任何输入都会让结果失效。

搜索不是全局最优异形套排。它只搜索有限行列和有限步距比例，不搜索任意角度、任意形状套排、多张不同规格材料联合优化。

### 11.6 结果表怎么读

主要列：

| 列 | 含义 |
| --- | --- |
| SET/Panel | 每张大料放多少个 SET |
| PCS/Panel | 每张大料出多少 PCS = SET/Panel × PCS/SET |
| SET 占大料% | SET 矩形面积 / 整张大料面积 |
| SET 占工作区% | SET 矩形面积 / 扣除四边后的工作区面积 |
| PCS 实际占 SET% | PCS 真实面积 / SET 面积 |
| PCS 实际占大料% | PCS 真实面积 / 整张大料面积 |
| 所需材料张 | 满足订单的最少整数张数 |
| 预计出货 PCS | 按良率和出货规则估算 |
| 超交 PCS | 预计出货 − 订单 |
| 已有材料预计 PCS | 已有张数能出多少 |
| 相对基准 PCS/Panel | 与基准方案的产出差 |

**SET 占料率和 PCS 实际面积利用率不是一回事。**  
SET 占料率把 SET 当完整矩形；PCS 实际面积用真实闭合外轮廓。面积利用率高不一定件数更多，相同材料下通常先看 **PCS/Panel**。

### 11.7 公式

所有面积单位 mm²，百分比乘 100：

| 指标 | 公式 |
| --- | --- |
| 大料面积 | PanelX × PanelY |
| 工作区面积 | (PanelX − 左 − 右) × (PanelY − 下 − 上) |
| SET 面积 | SetX × SetY（含 SET 工艺边） |
| 去工艺边 SET 区域 | (SetX − SET左 − SET右) × (SetY − SET下 − SET上) |
| SET 占整张大料 | SET/Panel × SET面积 / 大料面积 |
| SET 占工作区 | SET/Panel × SET面积 / 工作区面积 |
| 去边 SET 占大料 | SET/Panel × 去边SET面积 / 大料面积 |
| PCS 真面积占 SET | PCS/SET × 单PCS真实面积 / SET面积 |
| PCS 真面积占去边 SET | PCS/SET × 单PCS真实面积 / 去边SET区域 |
| PCS 真面积占大料 | PCS/Panel × 单PCS真实面积 / 大料面积 |

产出与出货：

```text
PCS/Panel = SET/Panel × PCS/SET
已有材料毛产出 = 已有张数 × PCS/Panel
按 PCS 良率预计出货 = floor(张数 × PCS/Panel × 良率)
按整 SET 良率预计出货 = floor(张数 × SET/Panel × 良率) × PCS/SET
所需材料 = 满足预计出货 ≥ 订单的最少整数张数
预计超交 = 预计出货 − 订单
```

软件会再校验“前一张数量不足”，避免浮点取整差一张。

订单为 0 时，所需张数和预计出货都为 0。

### 11.8 应用回 SET 拼版

选中方案后点“应用到 SET 拼版”（只有带真实几何的方案可用）。

软件会：

- 回填行数、列数、旋转、固定 SET / 步距、交错和手动筋；
- 自动切回“拼版 SET”页的预览；
- 重新生成 SET 和尺寸。

应用后必须检查：

- 行列数是否与方案一致；
- 工艺边、连接筋是否仍有效；
- 实际最小净距是否满足要求；
- SET 尺寸是否在工艺允许范围内。

自动搜索方案不会复用原手动连接筋，应用后需要重新确认。

### 11.9 预览与导出

“大料排布预览”页：

- 默认显示 SET 外框、编号、工作区、大料尺寸。
- 勾选“显示真实 PCS 外形（仅几何来源方案，最多 2000 PCS）”后显示真实 PCS。
- 最多 2000 PCS / 200000 顶点；超过会拒绝。
- 会检查 PCS 不超出对应 SET。

按钮：

| 按钮 | 行为 |
| --- | --- |
| 应用到 SET 拼版 | 回填行列、旋转、步距、手动筋，回到拼版页重新生成 |
| 生成大料排布图 | 在主窗口新标签打开；不自动保存 |
| 导出 | CSV 方案计算表、PDF 方案对比报告、DXF / PDF / DWG 大料图 |

CSV：

- UTF-8 BOM，Excel 打开中文正常。
- 包含面积、出数、良率、基准变化、大料预留、SET 间距、SET 工艺边、PCS 来源。
- 可用于独立复算。

PDF 报告：

- 含输入条件、结果表和变化量。

PDF 大料图：

- 适合页面，**非 1:1**。

DXF：

- 原生输出。

DWG：

- 仍需 ODA。

### 11.10 为什么 86.20% 不能直接照抄

附件示例大料 18.42 × 24.42 in = 467.868 × 620.268 mm，面积 290203.548624 mm²。

- 6 PCS/SET、107.20 × 194.41 mm：
  - 如果实际 11 SET/Panel，SET 占整张大料约 **78.996%**；
  - 如果 12 SET/Panel，约 **86.177%**。
  - 截图同时写 11 SET / 66 PCS 和 86.20%，说明它不是同一个“完整 SET 矩形占整张大料”口径。
- 4 PCS/SET、107.40 × 165.24 mm：
  - 16 SET/Panel 占整张大料约 **97.845%**。
  - 能否真的放 16 必须检查边距 / 间距；截图的 84.60% 可能扣了工艺边或采用其他面积口径。
- 新 SET 面积相对旧 SET 约 **−14.85%**；66 → 64 PCS 的产出变化是 **−3.03%**。

结论：**软件按你的实际输入重新算，不照抄附件数字。**

### 11.11 一个真实搜索例子

在测试条件：

```text

```

这只是一组参数下**已验证可行**的候选，不是批准的生产规格，也不是全局最优结论。生产前仍需核对：

- 原图版本和方向；
- SET 工艺边、连接筋；
- 材料纹理 / 层压方向；
- 设备能力、良率分布和抽检；

### 11.12 当前边界

- 仅软板二维几何及数量规划。
- 不包含硬板 V-cut、铣边补偿、叠板、铜层、层压、补强方向、强度规则。

- 预计出货是估算，不是保证。

## 12. 自动恢复与文件安全

### 12.1 快照

- 每 **60 秒**检查所有打开文档。
- 有修改的文档写成独立恢复快照。
- 也可“文件 → 立即创建恢复快照”。
- 后台写入不阻止继续绘图。
- **不会覆盖原 DXF / DWG，也不会把文档标记为已保存**。

位置：

```text
%LOCALAPPDATA%\EngineeringTools\CAD\recovery
```

### 12.2 恢复

异常退出后，正常启动会提示“恢复未保存图纸”。

流程：

1. 选中需要的快照。
2. 点“恢复选中”。
3. 恢复的图纸标题带“已恢复”，以未保存副本打开。
4. 按 `Ctrl+S` 会要求选择保存位置；建议另存为新的 DXF。

“稍后处理”保留快照；“丢弃选中…”会再次确认，只删除选中快照，不删除原图。

### 12.3 限制

- 不恢复撤销历史、选择、测量记录、视图状态。
- 60 秒是检查周期，大图排队或写入时可能更久。
- 尚未成功生成快照的修改不能恢复。
- 快照 DXF 数据限制 256 MiB。
- 自动恢复不是备份系统；请继续定期手动保存并保留原始 DWG 备份。

## 13. 常见问题

### 13.1 找不到“软板材料方案”入口

0.3.0 起已合并：

- 菜单和工具栏只有“拼版”。
- 打开“拼版”后，切到顶部的 **材料方案 / 利用率** 页。
- 旧命令 `FPCPLAN` / `MATERIAL` 仍然可用，但打开的是同一个窗口。

### 13.2 材料页没有当前 SET / 搜索按钮是灰的

- 还没有在“拼版 SET”页确认外轮廓并成功生成 SET。
- 当前 SET 没有真实 PCS 几何。
- 正在搜索 / 正在取消。
- 拼版参数改动后，当前 SET 已变化，需要重新生成。

解决：先在拼版页确认 PCS 外轮廓并看到 `PCS / ARRAY / SET` 状态，再切材料页。

### 13.3 打开后是空白

可能原因：

- 文件只有布局 / 3D / 不支持的代理对象。
- 所有图层被隐藏。
- 对象在模型空间之外。
- 文件解析失败但界面仍打开了空文档。

处理：

- 看命令区警告。
- 按 `Home` 显示全部。
- 检查图层可见性。
- 用另一款 CAD 确认文件内容。
- DWG 可尝试配置 ODA 再打开。

### 13.4 框选不到白色图框 / 横竖线

0.2.8 已修复零宽高包围盒问题。若仍遇到：

- 确认图框在可见且未锁定图层。
- 右 → 左交叉选择碰线即可。
- 对只读白色文字，点文字空隙也能选。
- 网格 / 坐标轴不是实体，不能用删除；用 `F7` 关网格。

### 13.5 删除没反应

- 对象在锁定图层。
- 只读预览不支持删除的类型。
- 当前不在选择工具。
- 先看命令区提示。

### 13.6 文字 / 标注不能编辑

- 外部标注不是可安全识别的单行文字。
- 复杂格式、嵌套标注、MTEXT 只读。
- 图层锁定。
- 选择的是标注线而不是文字；双击标注线或文字附近的空隙。

### 13.7 DWG 能打开但不能保存

保存 DWG 需要 ODA File Converter。没有 ODA 时：

- “保存”会进入 DXF 另存为。
- 原 DWG 不会被覆盖。
- 可在“文件 → 配置 DWG 转换器”指定 `ODAFileConverter.exe`。

### 13.8 拼版按钮没反应 / 打不开

- 当前文档有后台任务未完成。
- 没有有效选区或可见图形。
- 没有闭合外轮廓。
- 轮廓有断口 / 分叉，状态栏会显示问题端点。

### 13.9 自动识别出的 SET 不对

- 原图有多个版本轮廓 / 图框 / 多个视图。
- 自动识别把整图合并了。
- 候选标记“折线近似”。

处理：先在主画布框选单板，再打开拼版；或手动选准确外形线确认。

### 13.10 材料结果为空

- 材料工作区太小。
- 边距 / 间距太大。
- SET 尺寸超过工作区。
- 旋转 / 混排被禁止。
- SET 尺寸上下限过滤掉了所有候选。

材料页状态栏会说明原因。

### 13.11 为什么显示“未知”面积

手动输入的 SET 没有单 PCS 真实面积。软件不会用 SET 矩形面积除以 PCS 数来冒充真实面积。

解决：从拼版带入真实 PCS，或在表格里填真实单 PCS 面积。

### 13.12 改了参数，结果还在 / 导出还能点

0.3.0 的行为是：

- 修改材料输入后旧结果失效。
- 应用 / 生成 / 导出按钮禁用。
- 必须重新计算 / 搜索。

如果还能导出，说明输入没有触发失效，属于需要反馈的问题。

### 13.13 生成的大料图没保存

材料排布图和拼版图都是**新标签、未保存文档**。必须 `Ctrl+S` 或另存为。关闭标签时会提示保存。

### 13.14 PDF 尺寸不对

PDF 是 A4 适合页面，不是 1:1 工程比例。需要精确比例时，请用 DXF 或专业打印流程。

### 13.15 大图很慢

- 首次可见路径准备在 GUI 线程。
- 编辑后空间索引整树重建。
- 分析、读取、搜索是后台任务，但界面首次绘制仍可能等待。

建议：

- 缩小选区再分析。
- 关闭不需要的图层。
- 将大图拆成多个文件处理。
- 材料搜索预算到期时，缩小行列 / PCS 范围再试。

## 15. 推荐工作流（从原图到交付）

### 15.1 新任务检查表

- [ ] 确认单 PCS 闭合外轮廓，记录 PCS 尺寸和面积。

- [ ] 导出 CSV / PDF / DXF，独立复核。
