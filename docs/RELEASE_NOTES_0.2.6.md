# 0.2.6 键盘平移、缩放与视图菜单

## 新增操作

- 画布获得焦点时，方向键平移图纸：
  - `←` / `→` / `↑` / `↓`：每次 48 像素。
  - `Shift + 方向键`：每次 240 像素，快速移动。
  - `Ctrl + 方向键`：每次 12 像素，精细调整。
- 图纸跟随按键方向移动：按 `→` 时图纸向右移动，按 `↑` 时图纸向上移动，和“抓住图纸拖动”的中键平移手感一致。
- `+` / `=`：以鼠标位置为中心放大；`-`：缩小。鼠标不在画布上时以视口中心缩放。
- `Home` 仍为显示全部。
- “视图”菜单新增“居中选中对象”和“平移与缩放”子菜单，包含四个平移方向、放大和缩小，便于不使用键盘时操作。

## 焦点与输入安全

- 画布使用 `Qt::StrongFocus`，新建 / 打开文档后自动获得焦点，启动即可用方向键平移；关闭教程或恢复对话框后焦点也会回到画布。
- 方向键只在画布获得焦点时生效：命令栏输入时方向键仍移动文字光标，不会误触发平移。
- 菜单项不注册全局方向键快捷键，避免抢占表格、下拉框和对话框的正常键盘操作。
- 平移 / 缩放后按当前鼠标位置重新计算十字光标和状态栏坐标；中键拖动逻辑保持不变。

## 已知限制

- 方向键按屏幕像素平移，缩放比例很大或很小时每键对应的图形距离会不同。
- 命令栏、下拉框等控件获得焦点时方向键用于控件本身，需先单击画布。
- 高 DPI 下既有的像素取色测试仍以离屏结果为准；与本次键盘和菜单改动无关。
