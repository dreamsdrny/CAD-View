# 软板材料方案、利用率与预计出货（0.2.9 历史文档）

> **0.3.0 起材料方案已并入“拼版”窗口**，菜单 / 工具栏只保留“拼版”，材料内容在窗口顶部“材料方案 / 利用率”页。
> 当前统一说明、入口和公式见 [拼版与软板材料方案](PANELIZATION.md)；本页保留 0.2.9 独立窗口时期的公式与口径分析，供历史对照。

## 入口

- “工程分析 → 软板材料方案”、工具栏按钮，或命令 `FPCPLAN` / `MATERIAL`：输入已有 SET 尺寸/出数，比较大料排法。
- 在“拼版”里确认真实 PCS 外形后，点击“软板材料方案 / 利用率”：将当前 SET 和 PCS 模板带入，可后台计算不同 PCS→SET 拼版方式，再将选定方案应用回 SET 拼版。

层级明确区分：**PCS / Unit 单件 → SET 交货拼版 → Panel 大料**。现有拼版窗口的“固定 SET / 大板”指 SET 外框，不是本窗口的材料 Panel。

本版仅软板二维几何及数量规划，不包含硬板 V-cut、铣边补偿、叠板、铜层、层压、补强方向或强度规则。允许旋转必须经材料/工艺方向确认。

## 输入与操作

1. 输入大料 X/Y，选择 mm 或 inch。单位切换只换算大料、边距和材料 SET 间距，内部计算固定为 mm；不缩放原 CAD。附件示例 18.42×24.42 in = **467.868×620.268 mm**。
2. 设置大料四边预留、材料上 SET X/Y 加工净距。有效工作区域为扣除四边后的矩形，所有 SET 必须处于工作区域内、无重叠、满足指定净距。
3. 是否允许 SET 在材料上转 90°，是否比较左右/上下两个分区混排。材料有纹理/层压方向限制时关闭旋转和混排。
4. 输入订单 PCS 数、已有材料张数、预计良率以及“按 PCS / 按整 SET 良率”出货规则。
5. 已有 SET 表格允许多个方案：名称、SET X/Y mm、PCS/SET、单 PCS 真实面积 mm²、SET 四边工艺预留。面积未知填写 **0**，将显示“未知”，不以矩形面积代替。
6. 点“计算 / 比较已有 SET”。自动列出 0°、90°、实际含两种方向的分区混排，数量可行才显示；结果可按每张 PCS、所需张数、SET 占料率或 PCS 真面积利用率排序。
7. 若带入真实 PCS，设置搜索行列、每 SET PCS 最少/最多、SET X/Y 工艺上下限，决定 PCS 在 SET 内能否转 90°；点后台搜索。包含规则行列和交替行/列 180° 紧排步距候选，禁止镜像。有限候选搜索，不是全局最优异形套排。
8. 选择比较基准。带入的“当前 SET”会保留为基准方案；结果显示相对基准的面积变化、每 Panel PCS 变化、利用率百分点和材料张数变化。
9. 可“应用到 SET 拼版”回填行列/旋转/步距后生成工艺边/连接筋；或“生成大料排布图”在主窗口新标签打开。新图没有自动保存，请 Ctrl+S。

修改任何输入会使旧结果失效，必须重新计算后才能应用/生成/导出。搜索可取消，取消后的旧结果不能继续当成当前结果导出。

## 不同利用率的公式

所有面积单位 mm²，百分比乘 100：

| 指标 | 公式 |
| --- | --- |
| 大料面积 | PanelX × PanelY |
| 工作区面积 | (PanelX−左−右) × (PanelY−下−上) |
| SET 面积 | SetX × SetY（含 SET 工艺边） |
| 去工艺边 SET 区域 | (SetX−SET左−SET右) × (SetY−SET下−SET上) |
| SET 占整张大料 | SET/Panel × SET面积 / 大料面积 |
| SET 占工作区 | SET/Panel × SET面积 / 工作区面积 |
| 去边 SET 占大料 | SET/Panel × 去边SET面积 / 大料面积 |
| PCS 真面积占 SET | PCS/SET × 单PCS真实面积 / SET面积 |
| PCS 真面积占去边 SET | PCS/SET × 单PCS真实面积 / 去边SET区域 |
| PCS 真面积占大料 | PCS/Panel × 单PCS真实面积 / 大料面积 |

面积利用率高不一定件数更多；在相同材料、单板外形和工艺条件下通常优先比较 **PCS/Panel**。PCS 面积来自确认后的闭合外轮廓，没有扣除本版不参与模板的详细孔/铜层，不是净铜面积、钻孔后的材料量或 CAM 精度承诺。

## 产出、出货与取整

- 毛产出：`PCS/Panel = SET/Panel × PCS/SET`。
- 已有材料毛产出：`已有张数 × PCS/Panel`。
- 按 PCS 预计良率：`floor(张数 × PCS/Panel × 良率)`。
- 按整 SET 预计良率：`floor(张数 × SET/Panel × 良率) × PCS/SET`。这里良率是**整 SET 良率**，不把它误当 PCS 良率；整 SET 交货必须是 PCS/SET 的整数倍。
- 所需材料：满足预计出货 ≥ 订单的最少整数张数；会再校验前一张数量不足，避免浮点取整差一张。
- 预计超交：预计出货 − 订单；订单 0 时所需张数/预计出货为 0。

这些是数量估算，不保证实际出货，也不含抽检、报废分布、拼版之间故障相关性或库存占用。生产安全备料应按实际工艺另行评审。

## 附件示例的正确解读

18.42×24.42 in 大料面积为 **290203.548624 mm²**。

- 6 PCS/SET、107.20×194.41 mm：若真的 11 SET/Panel，占整张大料为约 **78.996%**；若 12 SET/Panel，则约 **86.177%**。截图同时写 11 SET / 66 PCS 和 86.20% 不是同一“完整 SET 矩形占整张大料”口径。
- 4 PCS/SET、107.40×165.24 mm：16 SET/Panel 占整张大料约 **97.845%**。能否容纳 16 必须检查边距/间距；截图的 84.60% 可能扣了工艺边或采用其他面积口径，不能直接照抄。
- 新 SET 面积相对旧 SET 为约 **−14.85%**；66→64 PCS 的产出变化是 **−3.03%**，本版可显示这类基准差异，但件数必须来自真实可行排布而非硬编码。

示例表仅初始化这两组 SET，默认材料四边各 10 mm、SET 间距 2 mm；请替换实际工艺条件后计算。没有自动把“14层/沉锡”等工艺描述当作几何约束，也没有自动猜测截图利用率的分母。

## 搜索边界与输出

- 每 SET 搜索行列最多各 8、PCS 最多 64；SET 内 0/90°及交替行/列/棋盘180°，紧排搜索若干离散比例，并按闭合实体重叠与真实线/弧净距验证。
- 每 Panel 最多 10000 SET；分区混排最多 250 个切分候选；预算不足明确提示，不保证找到所有更优方案。
- 自动搜索预算 512 个校验候选 / 45 秒（单个候选完成后检查），只发布已经完成几何验证的结果。规则方案建立回退，紧排不可行则拒绝。
- 材料上只比较规则网格、整体90°和左右/上下两种矩形分区；不包括任意角度、任意形状 SET、无限层级切分、整张材料自动开料或多张不同规格材料联合优化。
- 自动 SET 来源沿用当前 PCS/SET工艺边、最小净距；手动筋不复用。应用后重新生成工艺筋并确认。
- 图纸默认 SET 外框/编号/大料工作区/Panel长宽，可选真实 PCS 外形（最多2000PCS/200000顶点），不是 Gerber/Excellon 电路生产文件。
- CSV UTF-8 BOM（Excel中文），包含面积/出数/良率/基准变化及大料预留、SET间距、SET工艺边和PCS来源，便于复算。PDF 对比报告含输入条件、结果表和变化量；PDF 排布图适合页面、**非1:1**。DXF 原生输出、DWG 仍需 ODA。
- 只读预览不会被用户删除改动；生成主窗口图纸后才是普通可编辑实体。输入失效后禁止导出旧数据。
